# 原优化约束敏感性

从原优化页或系统数据中心进入`/motor-sensitivity`。选择一份保存数据及明确比较基准，点击“生成48组约束研究”。程序只复用原`screen_rows`评分与权重，不启动求解或训练，不修改原优化记录和默认阈值。

固定轴为脉动最小降幅10/20/30/40%、转矩最小变化−2/−1/−0.5/0%、铁损最大增幅0/2/5%，共48组；原默认30/0/0同时保留。权重沿用原0.6/0.3/10。V8_1原Control仍以原Baseline作为转矩下限，其他数据使用所选基准，和原单次筛选一致。

结果独立保存为`csens_...`，页面显示各组可行数/首选与默认组；下载配置摘要CSV、逐案例CSV、完整JSON和ZIP。每组保留全部原案例、未通过输入及原因，不把异常变为0分或删去。配置组数不是独立样品数，有可行组不能表述为原默认已改善。原数据的版本、处理/估算、实际CSV前缀、损耗及周期范围随结果保留。

页面同时展示“原默认配置下的逐案结果”：平均转矩、转矩变化、脉动及降幅、铁损及降幅、是否满足与未通过原因。直接读取已保存的默认组，打开记录即可看到零候选的具体原因，无需另存一次筛选。原负值、零值与缺失值分别显示，旧记录缺明细时明确提示下载原CSV，不补算、不改变已保存判据。

页面固定当前输入来源哈希，计算前后核对来源；来源变化时刷新重选，不自动换数据。等待期间保持单次提交，失败后先刷新记录，不自动重复。已有记录可重开或用网址`?study=...`直接恢复，只读保存结果，不重新评分；原始CSV和完整数据包从系统数据中心下载对应数据集。

研究保存在当前任务存储的`optimization_sensitivity/`，完整包保持私有。公开代码/薄证据不包含完整本地原生工程，也不增加物理可信度结论或最终电机排名。

公开的单数据集示例可独立重放，无需重新求解：

```powershell
python -X utf8 tools/replay_constraint_study.py --dataset-bundle calibration/bound_motor_archive_20261106/source_dataset.zip --reference ak_steel_m_6_carlite --storage data/constraint_replay
```

重放先核验单数据集清单、每个成员及原来源哈希，再按原评分生成一份新研究。示例包含6个已有案例及其JSON/CSV，含未通过项；不是完整私有工作包或原生工程，不作为新实验。相同数据应重现48组/36组有可行案/原默认0候选。源码和全部原文件仍须按各自使用范围解释。
