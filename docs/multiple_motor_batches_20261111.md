# 一次收集多个已完成电机批量

系统数据中心保留原单批量入口，新增“另外收集的已完成电机批量”，最多再选3份。可以把不同材料、31点与101点等记录收进同一个私有工作包，避免逐个下载后手工整理。只收集明确选择的已完成记录，不启动求解。

每批原结果ZIP放在 `calibrated_motor/<批量ID>.zip`，逐字节保存。`calibrated_motor/overview.csv` 汇总各批的每条材料：原平均/最小/最大转矩、脉动、原判据、点数、协议、模型、有效校准库和官方CSV哈希。零值、负值与异常保留；失败条目没有完整结果时指标留空。该表不生成跨协议排名，原CSV仍在各批原包内。

`data_index.json` 的 `calibrated_batches` 列出全部所选批量、原包哈希、测量协议及它们与所选校准的关系；原 `calibrated_batch` 字段继续保留主批量，兼容旧使用方式。其他批量可以单独选择，无需另选一个主批量或校准。

同一批量重复选择、来源已变化、活动任务或超过数量上限会提示修正。收集结束前再核对全部批量来源，防止前一批在收集后一批时变化。新工作包版本为V5；原V2/V3/V4包可继续读取，不修改旧包。

使用方法：进入首页的系统数据中心，选校准、数据集、主批量及其他批量（均可选），点击“生成所选数据工作包”，再下载。工作包只保存在本机，不随公开程序推送GitHub。不同协议、重复材料和曲线点数不能合计成独立实测样品数；零损耗B-H分支不计算效率。
