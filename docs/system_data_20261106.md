# 系统数据中心

首页“系统数据与下载”进入`/system-data`。这里列出实际保存的校准和电机数据，以及已注册的完整工作包。所有浏览与下载只读，不启动仿真、训练或新的优化筛选。

校准记录分别显示标定拟合和整材料留出误差，可重开对应材料及下载原报告。电机数据按模型版本、计算协议独立列出，显示保存条数、原判据通过条数、官方CSV来源且通过原判据的条数，下载沿用每个数据集自己的原文件和哈希。历史V8_1处理/估算与当前原生CSV结果分别标注，重复记录与曲线节点不等于独立样品数。

完整工作包是注册时的冻结快照。注册会复制包到当前任务存储，原包保留；重开网页或原包位置改变不影响已登记副本。每次下载核对整个ZIP和包内清单，字节改变时停止下载并保留现场，不切换到另一份包。核验表示文件完整性，不代表新增科学验证。工作包和完整原生工程不随代码自动发布。

## 在网页生成当前工作包

1. 刷新当前记录，明确选择校准、勾选需要的电机数据集，以及可选的已结束校准材料电机批量、已有原优化筛选。每项可不选，但至少选择一项；每包最多16份电机数据集。
2. 点击“生成所选数据工作包”。程序核对页面所选记录的来源哈希，收集已有材料包、原报告/曲线/误差、原生CSV及异常，不重新计算校准、预测或电机指标。
3. 完成后从“下载本次工作包”或完整包目录下载。生成的是`system_data_workpack_v3`；`selection.json`、`data_index.json`与成员哈希固定实际选择，旧包保留。来源已变化时提示刷新，不静默换库或加入其他数据集。响应丢失时可先刷新目录检查，不自动重发。

校准部分包含所选库的已有标定/留出材料包。电机数据集继续沿用各自原版本/协议与CSV出口；校准电机批量只接收已结束的记录，保留未通过的原标记、实际材料与转矩点，不开放零损耗效率或最终排名。所有生成入口只整理文件，在普通模式和CPU预览中均可使用，不代表GPU被禁用。

原优化筛选部分保留既有analysis.json、ranking.csv、analysis.md及原ZIP，并附明确关联该分析的原计划/状态。原评分、基准、约束、权重和“没有候选”不变，不新增筛选；历史V8_1处理/估算另有使用范围sidecar，不改写原报告。所选当前数据集与该原筛选的来源不一致时提示分开打包，不混用旧分析与新CSV。未选电机数据集时不会自动补入CSV，其源哈希仍在原筛选中；完整收集时应同时勾选对应数据集。

管理员也可注册已有`system_data_workpack_v2/v3`私有工作包：

```powershell
python tools/register_system_data.py --storage "本实例的任务存储" --file "已有数据包.zip" --title "系统数据V2" --description "冻结范围与用途"
```

任务存储必须与系统首页显示一致。同字节注册返回同一记录，不覆盖原名称和说明。入口不提供任意服务器文件路径的HTTP注册，也不提供删除旧包的操作。没有私有工作包的公开副本会显示空目录，已有校准和数据集仍可使用。
