# 取向硅钢系统使用说明

本系统把已有微磁平台、四样品曲线校准、材料文件和作者电机扫描/优化程序接到同一网页。原平台、原数据与已有结果保留；本文说明当前操作流程，历史开发记录不作为当前操作步骤。

## 启动

Windows双击 `start_system.cmd`，进入系统首页。启动器核对源码、资源目录、任务存储和运行模式，匹配时复用已有实例；旧版本占用端口时顺延，不关闭旧应用。以首页显示的实际地址为准。

主目录和magsim子目录的启动入口在完整工作区会使用同一任务存储；公开独立副本保留本目录存储。可先在PowerShell运行`.\start_system.cmd --check-config`只打印资源/记录路径与模式，不启动服务、浏览器或任务。

新启动器会保存服务地址提示，重开时先核对该地址的源码、资源、记录路径与模式；即使较早端口已空闲，也可复用当前匹配实例。提示失效时按原规则选择端口；`--no-fallback`仍仅使用指定端口，`--check-config`保持只读。

需要继续以前的工作，使用原任务存储。启动默认不恢复旧队列；重开页面可读记录，原生执行需要单独点击开始。缺少Maxwell许可时仍可使用校准、预测、CPU任务准备、旧结果浏览与下载。MuMax任务需要已配置的MuMax3和兼容GPU，电机原生任务需要现有AEDT许可。

本机Web使用.runtime/magsim、Maxwell worker使用.runtime/aedt；两套Python及依赖不同。原生任务还读取资源根目录的motor工程和已有许可。重开务必保持原资源根目录与任务存储；公开程序不包含完整私有工程，不能只安装Web依赖就视为已配置Maxwell。

首页“继续已有工作”列出保存的原生仿真、校准/材料和校准材料电机批量，可直接重开对应记录或保存预测。批量完成状态与原数值筛查分开显示；刷新只读取已有文件，不开始或接续计算。每类展示最多3份记录，更多记录从“查看全部”进入，单个目录读取失败不影响其他入口。

公开副本或全新任务存储最初没有私有历史记录。下文固定编号用于说明完整工作区的实例，初次运行请先建立自己的四样品校准，再使用页面实际生成的记录；公开的既有仿真数据可直接用于CPU校准，无需为此重新进行GPU仿真。

## 从四个样品建立或重开校准

1. 首页进入“材料校准”。已有校准直接从记录选择，不必重算。
2. 首次使用勾选B23R075、B27R090、B27R095、B30P105，建立校准并检验。页面显示参数、MuMax原生/参考RD、TD、标定曲线和整牌号留出结果。
3. 标定曲线用于已知样品对齐；检查其他材料的能力时看整牌号留出。下载对应材料与来源包，保留实际校准库及排除范围。

加载或新建校准后，页面地址保留当前校准编号，整页刷新或收藏重开仍使用该记录。指定校准不存在时提示重新选择，不自动切换到其他库。预测成功后可点击“在材料库打开此预测”，直接重开保存的材料、来源和下载，不重新预测。

查看B-H曲线时，地址还保留具体材料与RD/TD方向，整页重开保持同一组原始、参考、标定和留出曲线。原链接的材料/方向在当前校准中不可用时，清空曲线并提示选择，不静默显示另一组；切换查看不改变原数据或下载内容。

校准页的“研发对照 · 原生残差收缩”提供已冻结候选的只读预览：显式加载后可选择材料与RD/TD，查看原协议留出、候选留出与目标参考、逐项误差和未通过门限，下载JSON。切换校准记录会清除旧预览。它不重新选参、不更换当前校准库或材料，开发对照不作为新批次独立验证。

冻结研发对照现支持JSON、全部曲线CSV、逐项误差CSV和完整ZIP下载。CSV保留8组×26节点、24项误差和未部署/来源bank标记，切换图中材料不会筛掉下载数据；ZIP还包含说明和SHA清单。下载前无需重新执行仿真或预测。

## 添加其他材料

1. 首页进入“其他材料原生仿真”。选择校准库，输入材料代号、Goss比例、平均偏角、织构半宽、Si建模参数、厚度、晶粒数和随机种子。
2. 点击“生成独立仿真任务”：CPU生成取向与显式RD/TD脚本。检查保存参数，再点击“开始本任务仿真”。默认4晶粒/方向，最多8；串行使用一个GPU，累计120秒，单算例20秒。实际耗时取决于算例。
3. 暂停在当前晶粒结束后生效，显式接续保持原累计预算。失败和部分输出保留，不自动重试。 切换任务时先等待读取完成再操作，清空选择会解除旧任务；旧轮询不会重新选回先前任务。操作结果未确认时先刷新或检查原记录，不自动重复开始。
4. 成功后点击“打开原生对并修正材料”，确认实际校准库和预测范围，保存预测。预测不会自动训练或启动电机。

所有材料参数需明确填写；留空不会按0代入。参数无效时保持已打开任务，不创建新记录；Goss比例、偏角、Si建模参数或随机种子的明确0值仍按各自范围接受。等待CPU准备期间修改参数，原请求保存后仅提供其重开链接，不自动选为当前可启动任务；当前表单输入保持。

重开已有仿真任务后，可点击“用本任务参数填写上方表单”，一次载入其校准库、材料代号、四个建模参数、厚度、晶粒数和随机种子，再修改并准备独立任务。载入本身只改表单，不创建记录或开始仿真；对应校准库缺失时提示恢复，当前输入保持。

保存记录字段损坏时，目录将该项标为“文件待检查”或“需要检查记录”，其他完整记录仍可重开与下载。原文件保留供核查；接续需要有效的累计耗时，缺失、负值或非有限值不能按0重新计算预算。已保存原生对还会核对记录与JSON中的材料代号。

已有当前协议的冻结仿真，可在材料校准页直接导出原生对；已有JSON可上传。 切换校准或修改输入后，旧预测不会混入当前结果区；等待请求返回期间不重复提交。若之前的请求已在原校准下保存，页面提供原材料记录的重开链接；下载以该预测实际来源为准。旧参考修正训练CSV及无显式branch的旧table保持原用途，不直接改名转换为当前原生对。

从已有仿真导出原生对时，刷新来源与记录会保留仍可用的仿真来源和材料牌号；原来源或牌号消失会提示重新选择，并暂停导出按钮，选定有效材料后恢复。已保存原生对的下载仍指向原记录，不会因为刷新自动提取、预测或开始求解。

载入保存原生对、上传JSON、载入示例和手工编辑按最后一次输入操作处理。较早读取迟到时保留新输入，不自动应用预测；清空“保存的原生对”选择会解除旧记录及其载入按钮，当前预测JSON保持。

预测输入的JSON格式错误可直接修改，或重新载入文件/示例。页面清除本次预测的旧错误后等待手动应用，不自动重复提交；其他模块的错误仍保留。尚未加载校准时先选择有效校准，再应用预测范围。

## 材料库和电机多材料分析

材料库按“输入材料代号 · 预测编号”区分保存预测，显示建模参数、AMAT内部名、父库/有效库及排除范围。重开、刷新与下载都使用保存文件，不产生新预测。“材料到电机进度”同样支持按原材料代号搜索，详情显示保存参数、AMAT内部名与原数值判据。

材料库成功打开另一条材料后，当前网址同步保留其校准编号和材料条目；收藏或整页刷新可重开同一份曲线与下载。读取失败或较早请求迟到时，不把地址改到未打开的材料。链接指定记录缺失时先显示错误，再从现有列表手动选择。

- 只分析一种材料：点击“准备或接续电机分析”。它优先复用已有步骤，只补CPU准备；原生导入和转矩执行另行手动开始。
- 刷新材料时保留当前校准下仍有效的勾选；切换校准会清空选择。切换批量记录时，等待加载完成后再操作；加载或读取失败期间旧操作与旧下载会清除，避免指向其他批量。
- 多材料一起分析：进入“校准材料批量分析”，选择1–8份标定、留出或预测材料，准备批量计划。查看新增导入/求解预算后点击“开始串行分析”；程序自动依次导入、准备工程、求解和整理官方CSV，已有结果复用。
- 请求暂停后等待当前阶段结束。保留批量网址，重开后显式接续；已尝试失败项保持可见，不自动重试。
- 结果表把新增/复用阶段与原数值判据分开列示，计算结束的异常结果仍保留。摘要分别统计新增、复用、通过、未通过与未报告。
- 叠图默认保留全部原始点，可勾选材料、只看通过原判据的波形、清空或恢复；坐标随所选曲线缩放。刷新和复制当前链接保留筛选，换批量时重新显示全部。显示筛选不会改变下载包。
- 下载包包含逐案来源、指标、文字摘要和全部已有官方CSV，新增 material_inputs.json / material_inputs.csv 对应原输入代号、四项建模参数、材料键与bank；仅在材料包哈希和冻结批量来源一致时填入参数，否则明确显示无法核对。建模参数不是实测成分或认证证明。异常结果可进入独立分析页查看原值、相邻点和求解记录。

校准B-H分支当前整理转矩，损耗系数没有独立标定，因此不生成效率或最终材料排名。输入的建模参数不认定为新实测成分/EBSD；原生仿真完成也不等同于材料精度或晶粒数收敛证明。

转矩分析页刷新时保留通过“查看本材料转矩”选中的执行任务。地址同时保存执行编号，“本条结果链接”和“本条记录链接”可用于收藏或重开；批量表、进度详情和材料接续入口也对应各自的执行记录。指定记录没有结果或不属于当前计划时明确提示，不自动换成另一条结果。结果未变化会保留已打开的异常检查；所选记录暂不可读时可等待刷新或选择其他记录。参考曲线继续单独展示。

独立转矩页在准备任务、开始一次分析或准备分析工程等待时保持单次请求，刷新状态不会提前重新启用。操作结果未确认时先刷新原计划/执行记录，不自动重复创建或开始。

独立转矩结果页同时显示电磁机械功率，使用当前执行记录已核验的转速，按平均转矩×2πn/60折算。它未扣机械损耗，不等于铭牌额定功率；缺少已核验工况时显示空值，不使用页面其他计划或默认转速。零值与负值保留，原CSV、指标JSON和数值异常状态不改。

校准材料批量表同样显示电磁机械功率和保存转速，逐条匹配执行ID、材料/有效库、分析计划、周期、结果版本及转矩CSV后读取。缺少工况时显示“工况未核对”，原转矩与异常仍可用；刷新或切换批量不会把迟到的其他记录写入当前表。网页工况显示使用只读查询，原JSON和官方CSV保持。

“准备或重开批量计划”等待返回时，可继续修改材料、核数、协议或查看其他已保存批量。旧请求返回后保留当前选择，并提供原请求已保存计划的直达链接；同一准备请求不能重复提交。准备成功不自动开始原生分析，失败不会自动重试；先检查保存清单，再决定是否重新准备。

批量汇总包另含`operating_points.csv`和`operating_points.json`，列出每条材料的保存转速、平均转矩、折算功率、执行编号、原CSV哈希与核对状态，文字摘要也包含对应工况表。仅使用本条已核验执行的工况，无法核对时转速和功率留空；零值、负值及原数值异常保留。原官方CSV、原转矩汇总和原批量JSON不改写。

批量结果中的“与指定基准比较”允许选择一个已有转矩结果，再点击读取，查看各材料相对基准的转矩/功率差和百分比，单独下载比较CSV或JSON，也可点击“下载比较及原CSV完整包”一次获取比较、原批量摘要和官方CSV。ZIP的saved_batch_report目录保留原汇总包成员，顶层manifest列出全部文件哈希；比较使用包内同一批量快照。差值按当前条目减基准，百分比以正的基准为分母；零或负基准只列绝对差。模板、模型版本、分析协议或保存转速不同，以及工况无法核对的条目会保留原因和空差值。标定库/留出范围差异与原数值异常逐项标注，保持选择顺序，不自动排名。切换基准或批量后，旧请求不会覆盖新选择；刷新同一未变化结果可保留已读比较。此功能只读已有记录，不新增预测或求解，原汇总包内容保持。

## 沿用作者原库扫描和优化

电机扫描核数需为1–32整数，小数不会截断成另一个核数；至少勾选一种牌号后才准备。每个扫描任务可展开“查看保存配置”，核对其冻结核数、周期协议、模型、材料、设计/求解设置和模板标识，也可下载原配置JSON。队列轮询保留已打开配置；读取失败可显式重读，查看只发出读取请求，不提交求解。

单个扫描状态损坏时，该项显示“记录不可读”及原状态/配置下载，其他完整任务和原库优化数据集仍可浏览。队列状态暂不能确认时，原生动作等待刷新恢复；只读记录、配置与原始下载保持可用。异常文件留在原目录供核查，系统不替写其状态。

分析已有材料库牌号时，进入“电机工作台”多选、准备并提交串行扫描；“电机优化流程”连接作者原基线、插片对照、多牌号结果、约束与权重。选择同一数据集/协议的基准后保存筛选配置，可下发新计划或查看已完成计划。原作者程序、旧结果及其指标定义保留；不要混用不同版本的效率和转矩作为同一次比较。 修改数据集、基准、约束或权重后，旧筛选会隐藏；迟到的旧请求只保存在历史中，不覆盖当前选择。结果区列出实际来源、周期与基准。同一计划待返回时不能重复提交，刷新结果清单保留最后选择。

既有库牌号扫描的提交、仅继续未尝试牌号及汇总操作在等待期间保持单次请求，轮询不会重新启用按钮。读取失败或操作结果未确认时先刷新并核对原任务；后续任务仍需手动提交，不自动重试失败案。已有官方CSV和汇总下载继续保留。

官方波形对比页刷新目录会保留仍可用的模型/周期和算例选择，按来源数据集与算例编号对应，不因目录排序变化改选其他算例。已消失或不可用的项会说明；模型/周期消失时需手动重新选择。刷新后点击“显示所选波形”读取当前所选结果，原CSV、数值和下载口径保持。

优化页的“已保存的筛选记录”可直接查看原排序、六项配置、基准和下载。点击“沿用此配置”前会核对当前数据集版本、协议、来源哈希和基准，成功后只恢复上方输入；原保存结果单独保留，新筛选仍需手动保存。来源变化或读取期间用户另改配置时不覆盖当前输入，不自动下发计划或求解。
