# 取向硅钢系统使用说明

本系统把已有微磁平台、四样品曲线校准、材料文件和作者电机扫描/优化程序接到同一网页。原平台、原数据与已有结果保留；本文说明当前操作流程，历史开发记录不作为当前操作步骤。

## 启动

Windows双击 `start_system.cmd`，进入系统首页。启动器核对源码、资源目录、任务存储和运行模式，匹配时复用已有实例；旧版本占用端口时顺延，不关闭旧应用。以首页显示的实际地址为准。

主目录和magsim子目录的启动入口在完整工作区会使用同一任务存储；公开独立副本保留本目录存储。可先在PowerShell运行`.\start_system.cmd --check-config`只打印资源/记录路径与模式，不启动服务、浏览器或任务。

需要继续以前的工作，使用原任务存储。启动默认不恢复旧队列；重开页面可读记录，原生执行需要单独点击开始。缺少Maxwell许可时仍可使用校准、预测、CPU任务准备、旧结果浏览与下载。MuMax任务需要已配置的MuMax3和兼容GPU，电机原生任务需要现有AEDT许可。

本机Web使用.runtime/magsim、Maxwell worker使用.runtime/aedt；两套Python及依赖不同。原生任务还读取资源根目录的motor工程和已有许可。重开务必保持原资源根目录与任务存储；公开程序不包含完整私有工程，不能只安装Web依赖就视为已配置Maxwell。

## 从四个样品建立或重开校准

1. 首页进入“材料校准”。已有校准直接从记录选择，不必重算。
2. 首次使用勾选B23R075、B27R090、B27R095、B30P105，建立校准并检验。页面显示参数、MuMax原生/参考RD、TD、标定曲线和整牌号留出结果。
3. 标定曲线用于已知样品对齐；检查其他材料的能力时看整牌号留出。下载对应材料与来源包，保留实际校准库及排除范围。

校准页的“研发对照 · 原生残差收缩”提供已冻结候选的只读预览：显式加载后可选择材料与RD/TD，查看原协议留出、候选留出与目标参考、逐项误差和未通过门限，下载JSON。切换校准记录会清除旧预览。它不重新选参、不更换当前校准库或材料，开发对照不作为新批次独立验证。

## 添加其他材料

1. 首页进入“其他材料原生仿真”。选择校准库，输入材料代号、Goss比例、平均偏角、织构半宽、Si建模参数、厚度、晶粒数和随机种子。
2. 点击“生成独立仿真任务”：CPU生成取向与显式RD/TD脚本。检查保存参数，再点击“开始本任务仿真”。默认4晶粒/方向，最多8；串行使用一个GPU，累计120秒，单算例20秒。实际耗时取决于算例。
3. 暂停在当前晶粒结束后生效，显式接续保持原累计预算。失败和部分输出保留，不自动重试。 切换任务时先等待读取完成再操作，清空选择会解除旧任务；旧轮询不会重新选回先前任务。操作结果未确认时先刷新或检查原记录，不自动重复开始。
4. 成功后点击“打开原生对并修正材料”，确认实际校准库和预测范围，保存预测。预测不会自动训练或启动电机。

已有当前协议的冻结仿真，可在材料校准页直接导出原生对；已有JSON可上传。 切换校准或修改输入后，旧预测不会混入当前结果区；等待请求返回期间不重复提交。若之前的请求已在原校准下保存，页面提供原材料记录的重开链接；下载以该预测实际来源为准。旧参考修正训练CSV及无显式branch的旧table保持原用途，不直接改名转换为当前原生对。

## 材料库和电机多材料分析

材料库按“输入材料代号 · 预测编号”区分保存预测，显示建模参数、AMAT内部名、父库/有效库及排除范围。重开、刷新与下载都使用保存文件，不产生新预测。“材料到电机进度”同样支持按原材料代号搜索，详情显示保存参数、AMAT内部名与原数值判据。

- 只分析一种材料：点击“准备或接续电机分析”。它优先复用已有步骤，只补CPU准备；原生导入和转矩执行另行手动开始。
- 刷新材料时保留当前校准下仍有效的勾选；切换校准会清空选择。切换批量记录时，等待加载完成后再操作；加载或读取失败期间旧操作与旧下载会清除，避免指向其他批量。
- 多材料一起分析：进入“校准材料批量分析”，选择1–8份标定、留出或预测材料，准备批量计划。查看新增导入/求解预算后点击“开始串行分析”；程序自动依次导入、准备工程、求解和整理官方CSV，已有结果复用。
- 请求暂停后等待当前阶段结束。保留批量网址，重开后显式接续；已尝试失败项保持可见，不自动重试。
- 结果表把新增/复用阶段与原数值判据分开列示，计算结束的异常结果仍保留。摘要分别统计新增、复用、通过、未通过与未报告。
- 叠图默认保留全部原始点，可勾选材料、只看通过原判据的波形、清空或恢复；坐标随所选曲线缩放。刷新和复制当前链接保留筛选，换批量时重新显示全部。显示筛选不会改变下载包。
- 下载包包含逐案来源、指标、文字摘要和全部已有官方CSV，新增 material_inputs.json / material_inputs.csv 对应原输入代号、四项建模参数、材料键与bank；仅在材料包哈希和冻结批量来源一致时填入参数，否则明确显示无法核对。建模参数不是实测成分或认证证明。异常结果可进入独立分析页查看原值、相邻点和求解记录。

校准B-H分支当前整理转矩，损耗系数没有独立标定，因此不生成效率或最终材料排名。输入的建模参数不认定为新实测成分/EBSD；原生仿真完成也不等同于材料精度或晶粒数收敛证明。

## 沿用作者原库扫描和优化

分析已有材料库牌号时，进入“电机工作台”多选、准备并提交串行扫描；“电机优化流程”连接作者原基线、插片对照、多牌号结果、约束与权重。选择同一数据集/协议的基准后保存筛选配置，可下发新计划或查看已完成计划。原作者程序、旧结果及其指标定义保留；不要混用不同版本的效率和转矩作为同一次比较。 修改数据集、基准、约束或权重后，旧筛选会隐藏；迟到的旧请求只保存在历史中，不覆盖当前选择。结果区列出实际来源、周期与基准。同一计划待返回时不能重复提交，刷新结果清单保留最后选择。
