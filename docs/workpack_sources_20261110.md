# 校准与电机批量的实际来源关系

数据中心的电机批量选项会列出其保存的校准记录。组合工作包自动写入每条材料的原校准记录、材料键、父/有效子bank及排除范围，并与另选校准记录比较。相同父库不代表预测子库相同，相关标记分别记录。

选择新校准和旧电机批量时可以分别归档。工作包说明会明确提示来源不同，data_index.json中的calibrated_batch.calibration_relation列出实际关系，不把旧电机结果称为使用新校准重新求解的成果。旧记录缺少来源时标为unknown，不按所选校准补填。

原校准、曲线、原生CSV、批量报告、指标与数值判据均保留；此更改只补来源关系，不重新预测、训练、求解或评分。完整包仍为本机私有快照。
