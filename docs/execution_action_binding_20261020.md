# 独立转矩执行页的单次操作

旧页在准备独立执行任务等待时仍能再次准备，刷新会重新启用按钮；原生开始按钮和分析工程准备也可能在等待中被状态刷新重新创建或启用。原后端已有执行锁，但重复准备会产生无用副本和含混状态。

现在准备任务、手动原生开始和分析工程准备各保持单次请求；执行列表和计划刷新仍保留等待状态。原生开始还须匹配已读取的prepared任务和当前可执行资源，CPU或资源不可读时只保留准备/查看。返回记录核对计划或任务ID；结果不明确时提示检查原记录，不自动重试。成功后仍由原状态与预算决定下一步，不自动开始新任务。

原执行/材料/诊断后端、求解预算及作者优化程序保持，上一项修复的所选转矩结果和异常检查保留行为继续通过。新测试使用模拟POST：重复准备由2次降为1次，同时覆盖刷新期间开始按钮、工程准备、CPU限制和身份不符。真实页面只重开已有DEMO结果、查看保存检查并刷新，原生操作0、真实新准备0。
