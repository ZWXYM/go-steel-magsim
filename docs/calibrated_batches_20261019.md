# 校准材料批量分析

从系统首页或材料库进入“校准材料批量分析”。选择保存的校准记录，勾选1–8种材料，设置1或2核及1周期/3周期协议。四个标定样品可一键选择；标定、整牌号留出和保存预测分别标识。

## 操作流程

1. 点击“准备或重开批量计划”。系统复用匹配的材料、副本、导入、分析计划和已有结果，只补齐缺少的CPU准备步骤；此操作不启动AEDT。相同来源、配置和程序版本重开同一批量。
2. 查看预算后点击“开始串行分析”。独立控制进程按选择顺序逐项推进：复用已有结果，或实际导入/保存预检→分析工程复制→独立转矩执行→官方CSV整理。不会并行启动多项原生求解。
3. 可请求“当前阶段结束后暂停”。当前原生阶段正常结束后停止后续派发，不杀进程；重开准确的批量链接，再“显式接续当前批量”。已完成阶段和结果不重复计算。
4. 查看逐项状态、转矩及原始点叠图，打开独立分析页，下载批量包。包含逐案来源/指标CSV、文字任务摘要、原转矩CSV及文件哈希；失败和未完成项保持可见。

每次新导入最多240秒，每次电机分析最多1200秒、2核、0GPU。批量准备会列出最多新增导入、求解和会话数；已有结果不计新增。预算、原始文件、程序及父子记录绑定。失败、过期、超时、归属不明的现场不会自动重提；控制器中断需显式接续。

## 执行与结果隔离

短交接锁与持久批量归属共同保护派发。批量控制期间，新版系统的普通扫描/导入/转矩开始请求受到保护；只允许已验证的活动控制器推进自身阶段。Windows Python启动器与真实子进程按PID、创建时间、任务token及直接亲子关系交接。只有原有专用worker按身份核对释放本次新建的AEDT会话，不关闭用户已有应用。

批量记录位于共享存储的`calibrated_motor_batches`，原`motor/scan_*`、原始结果和作者优化程序保留。控制器不重跑原MuMax、校准或预测。所有转矩均来自对应独立执行的官方CSV；叠图显示全部原始点，不平滑或重采样。汇总保持选择顺序，标明模型版本、周期、有效库及排除范围，不给不同来源强行生成最终排名。

摘要生成器核对原汇总包哈希，保留原CSV/JSON字节，另增`summary.md`与来源清单。零值保持为零，缺失量显示“—”，未完成项不填造结果。B-H材料暂无独立损耗数据，当前不计算效率或最终优化排名。
