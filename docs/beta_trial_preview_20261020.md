# 冻结CPU候选的网页预览（2026-10-20）

材料校准页新增可折叠的“研发对照 · 原生残差收缩（只读，未部署）”。先加载保存的四样品跨材料校准，再显式点击“查看冻结CPU候选对照”。它读取已发布的固定试验结果，不重新拟合或选择参数，也不替换材料。

页面可切换四种材料和RD/TD，显示原协议材料留出、候选材料留出与目标参考的26个原H节点，并显示所选方向的候选RMSE与B800误差。三方法汇总表和五项原接受条件同时可见；均值改善不掩盖未通过的全部B800门限。仅参考内插对照的统计与图中的目标参考曲线分别标记，已知样品标定拟合也与这组外层留出对照区分。

例如B30P105 TD候选RMSE=0.058643T、B800误差=+0.053621T，仍未达到0.05T门限。原模型的逐材料留出汇总仍是0.04404265T；候选0.03080127T仅用于研发预览，不用于本次材料出口或电机比较。

后端先核对当前bank的规范哈希，再读取限定的冻结文件和SHA256，核对协议、8组材料/方向、物理H、参考、留出权重成员、24行逐项指标和接受状态。来源不同或文件改变会给出错误，保留正常校准页面。源数据兼容主工作区与公开副本两种目录布局。API只有GET：

- `/api/workbench/calibrations/<id>/beta-trial-preview`
- `/api/workbench/calibrations/<id>/beta-trial-preview/download`

下载JSON包含全部8组曲线、24行指标、冻结候选协议、内层选择和来源哈希，并标记只读/未部署；不包含bank或AMAT出口。前端打开页面不自动请求候选，不发送POST；切换校准会清空旧预览，迟到响应与读取错误不会混入当前记录。

真实网页已验证B30P105/TD、78个曲线节点、切换校准清除视图，以及下载与冻结结果数组一致。主469项后端测试、167文件AST与10项前端专项通过，其中新增8项后端检查和1项前端专项。4983旧存储文件集合/SHA不变，45旧公开数据树保持。此增量原生/Maxwell/MuMax/候选评估/ML训练/保存预测/电机准备均0，累计45/682不变，论文未写。
