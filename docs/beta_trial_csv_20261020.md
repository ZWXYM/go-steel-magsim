# 冻结候选对照下载

在“材料校准与电机扫描”载入四样品跨材料校准记录，展开“研发对照”，点击“查看冻结CPU候选对照”。可分别下载JSON、全部曲线CSV、逐项误差CSV，也可下载完整ZIP。

曲线CSV保存四材料RD/TD共8组、每组26个原始物理H节点，共208行；三列B分别为原协议材料留出、候选材料留出和已有目标参考。切换网页的材料或方向只改变图，不删减下载内容。误差CSV保存3种方法×8方向的24行，保留完整浮点值，缺失指标留空、零值和误差符号保留。CSV采用UTF-8 BOM，含H/B单位、校准编号、规范bank SHA及“retrospective_whole_material_holdout / not_deployed”标记。

ZIP只读取一次保存对照，包含preview.json、curves.csv、metrics.csv、README.md和manifest.json。manifest逐一绑定前四个文件的SHA256，离线仍可核对来源；不包含材料AMAT，不改变当前材料库或默认预测。冻结五资产和当前bank身份不匹配时明确返回错误，不重新拟合或混用。
