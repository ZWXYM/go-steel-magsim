# 后台任务日志与工作目录导出

原run_task为每个后台线程直接替换进程sys.stdout。两个任务重叠时，A的输出会进入B，B的一段输出会漏到外部；最后完成的任务还可能恢复到另一个已结束任务的缓冲，影响后续控制台日志。这一错误已用两个独立事件控制的合成任务复现。

现在文本输出按当前任务线程归属收集，作用域进入/退出由短锁保护，计算函数仍并行运行。其他线程沿用原输出流；任务完成、失败或嵌套捕获后正确恢复，退出时不会覆盖其他组件主动替换的输出流。原状态、结果、error/traceback、时间及任务查询接口保持；原生/子进程已有日志入口不改。

8项专项覆盖并行/外部输出隔离、嵌套、异常、普通流属性、无控制台回退、外部替换归属、真实run_task成功/失败和参数传递。复现中A/B的完整输出现分别属于各自任务，进程stdout恢复。没有通过串行锁住长计算来掩盖问题。

另已复现切换工作目录后材料保存成功、HTTP下载却返回500：旧相对路径被Flask按程序目录解析。HTTP独立材料保存现在先绑定绝对目录，下载与metadata引用同一文件；原脚本未使用artifact_name时的默认路径保持。临时工作区前后对照为500→200，AMAT材料内容不变，增加1项接口回归。没有重算原生或重训练模型。
