# 从完成计划一键整理官方结果

在原优化页“配置扫描与自动筛选”的已完成计划旁，点击“整理官方结果包”。程序自动找到该计划的同任务数据集、原筛选、基准和配置，保存一个完整结果包并登记到现有数据中心；无需再分别勾选数据集与筛选。相同来源重复整理会重开同一包。

工作包保留原计划和完成状态、四项原筛选出口、该任务全部案例及官方CSV/来源；异常与零候选不变。原数据集与保存筛选来源不同、基准或配置不符时停止整理。未完成或基准失败的计划显示原原因，继续保留原任务，不自动重算或替换基准。

整理不启动求解、训练或新评分；普通模式及显式CPU预览都可整理已保存结果。包为固定私有快照，完整原生工程、缓存和日志仍在原任务目录。下载后仍应按原版本、周期和损耗/本构范围解释，包完整不代表独立实测认证。
