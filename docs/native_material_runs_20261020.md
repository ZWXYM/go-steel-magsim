# 其他材料原生仿真与系统衔接

从系统首页进入“其他材料原生仿真”，或打开 `/native-material-runs`。沿用原织构采样和脚本生成程序，增加一个与所选校准库兼容的独立任务入口；原平台仍可使用，旧脚本和数据保持。

## 操作

1. 选择已保存的校准库，填写材料代号、Goss比例、平均偏角、织构半宽、Si建模参数、厚度、晶粒数和种子。点击“生成独立仿真任务”只运行CPU准备，冻结取向、脚本、参数、采样协议、校准库和程序版本。
2. 点击“开始本任务仿真”才下发MuMax。单任务最多8晶粒/方向，RD/TD串行使用一个GPU，累计120秒、单个算例20秒。默认4晶粒/方向；实际能否在预算内完成取决于算例。请求暂停后等待当前晶粒结束，显式接续仍使用原累计预算。
3. 完成后自动导出未经参考修正的 `raw_pair.json` 及来源记录。点击“打开原生对并修正材料”，确认校准范围，再保存预测。系统不会自动预测、训练或启动电机。
4. 在材料库重开保存预测，下载曲线、AMAT和metadata；“准备或接续电机分析”只补齐CPU准备。校准材料批量页可与其他标定、留出或预测材料共同选择，已有结果复用，原生执行另行开始。

刷新和重开页面只读保存状态。任务失败、部分table和旧程序副本保留，不自动重试；“检查中断现场”只在工作进程已退出且没有活动MuMax时记录失败，不关闭任何进程。任务、原始table、取向和导出文件位于当前首页显示的任务存储目录。

CPU预览和源码已更新的旧进程仍可准备、查看、下载；GPU开始按钮会禁用。运行启动器打开匹配版本，旧实例保留。任务启动后，其他材料或电机原生下发由共享调度窗口协调。

本增量没有新Maxwell求解或训练。新材料的电机导入/求解尚未执行；既有校准材料的实际电机执行证据见此前单案和批量记录。4,130个旧存储文件和525个冻结pilot文件SHA不变。主435项软件测试通过，13项本功能测试包含真实CPU脚本准备和模拟执行/异常场景，9项前端专项通过；软件测试不等同于真实材料精度验证。

这是1晶粒的功能接口例子，输入参数不是新增实测牌号/EBSD证据。有限晶粒、独立精度和损耗仍未验证，质量标记保持unassessed，旧bank和留出误差未改。回线中点工程代理不当作实测初始磁化曲线；B-H分支只做转矩，不补造损耗、效率或最终排名。原作者材料库优化流程继续保留。论文写作暂停。
