# 原脚本执行面板与串行队列

保留原BAT/PowerShell等脚本和求解命令。执行面板固定当前脚本与作业ID，忽略旧面板的迟到状态、日志、停止响应；关闭面板只断开显示连接，不停止后台进程。排队轮询关闭后释放，连接中断可重新读取当前任务。提交等待中反复打开同一脚本复用原请求，失联重试沿用相同请求ID；已完成后再次执行才创建新请求。

后台对提交与队列推进使用同一串行锁，避免两个并发请求同时决定启动。请求ID与脚本绝对路径及创建目录绑定，重复请求返回原任务，清理终态卡片后保留小型请求回执。任务记录缺失时明确提示，新建执行需用户再次点击，不自动重提。创建目录用于子进程cwd，队列取消会移除待发项且不发送进程信号。

运行中停止只发送一次原有停止信号，状态保持“停止中”，直到原读线程确认进程结束；正在启动且尚未取得进程时提示稍后重试。仍在运行的进程不会因终态标志或清理卡片而被队列忽略。新增验证全部使用模拟worker、模拟进程和临时脚本，未启动MuMax、未调用真实停止接口，也未关闭用户应用。
