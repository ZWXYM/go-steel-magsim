# 101点电机协议与专用预算停止

材料库和校准材料批量页新增 `v8_2_cycle1_RD_equivalent_intrinsic_fine100_v1`，使用 RD 等效 Intrinsic 材料、0.1 ms 时间步、100步/101个官方点、10 ms 窗口、3000 r/min。平滑及非线性迭代设置与原 Intrinsic 平滑协议相同，材料仍采用原26个物理 B-H 节点。默认协议和已保存的31点结果不变。

新协议具有独立模型版本 `V8_2_scalar_RD_equivalent_BH_only_intrinsic_fine100_v1`。解析器要求官方CSV确有101点且时间网格完整；不能把31点插值成101点。支持官方纳秒时间列。批量计划、执行、页面预算及材料导出均使用该协议自己的采样信息。

新协议单次固定预算为1800秒、最多2核，旧协议仍为1200秒。预算依据此前 B23R075 实际101点控制耗时1549秒制定；此前控制仍保留“超过当时1200秒预算”的记录，不能追溯标成合规。未开始的计划可从网页准备、重开，再显式开始串行分析。

## 已有结果和本轮验证范围

已有独立控制 `native_intrinsic_fine100_control_v1` 的 B23R075 官方101点：平均转矩1.863559456 N·m，最小1.097243021、最大2.123832057 N·m，脉动55.087538671%。该案通过原转矩数值判据；它保留原私有控制身份，不冒充新正式执行。新解析器读取其原CSV得到相同指标。原31点异常波形完整保留。

专用停止器改为在开始求解前，按确切版本/PID连接唯一Windows ROT条目，核验原生PID、进程创建时间、本案工程路径和队列归属后才标ready；到期复用该连接并再次检查，调用 `StopSimulations(True)`。没有任意桌面回退或进程终止。连接或核验失败会阻止开始求解。

本轮已在一个全新专用会话完成实际活动求解中断测试：采用45秒加速截止，仅测试机制，未声称真实经过1200秒。原生返回stopped，工作进程拒绝采集为完整结果，专用会话释放且已退出，源文件不变；0新增完成物理求解。原生停止请求至求解返回仍需时间，预算到达并不等于进程瞬时退出。

正式 B27R095 单案细步长批量 `bhbatch_30448dd50095` / 执行 `bhexec_09d5b52d199a` 已完成：复用既有导入，1次新电机分析、0新导入；101点平均1.869905354 N·m、最小1.024094206、最大2.127107102 N·m，脉动58.987632385%，通过原判据且未超1800秒预算。约24分钟完成求解。转矩按3000 r/min折算电磁机械功率587.448 W，未扣机械损耗。实际保存设置、26材料节点和官方CSV已读回核对，专用会话已释放。该案沿用全库标定材料，不新增独立B-H验证；证据见 `calibration/fine100_system_20261111`。

## 使用边界

这些是单方向标量等效材料的工程比较。细化时间步没有新增实测 B-H、没有改变校准库或材料留出误差，也没有验证其他所有材料。零损耗占位材料不计算效率或最终材料排名。作者原材料库的牌号扫描、优化评分和已有电机结果保持独立可用。
