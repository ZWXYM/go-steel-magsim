# 材料到电机进度入口

系统首页新增 `/material-motor`，汇总保存材料 → 电机副本 → 原生导入 → 转矩分析工程 → 独立执行与结果。无需重新校准或预测；点击下一步会打开已有操作页面，本页没有任务创建、求解派发或自动重试入口。

## 使用

选择“只看已有电机副本”，或按材料、样品、记录编号筛选。点击材料查看各条保存链路、失败/超时/过期状态及下一步。现有普通实例使用本机5005，旧实例和应用保留。

材料链接精确携带校准记录和条目，材料库刷新后保留当前选择。不存在的链接目标明确报错，不默认打开另一个材料。分析计划可直接返回自己的进度链路，避免返回默认材料。

准备、导入、工程复制和结果分别显示。只有已有执行模块核验通过的实际官方转矩才进入结果计数；历史参考不计入当前材料结果。超预算完成仍提示检查，失败与身份不明记录保留，不提供自动重试。

## 来源与下载

链路依照已核验的父子ID、材料名、父库/有效库、训练样品与完整牌号排除关联；材料AMAT及metadata原字节也与电机副本绑定。同材料名但来源或字节不同的记录不能合并。损坏、孤立或暂不可读记录单独显示，部分模块读取失败不能被误解为“尚无记录”并诱导重复创建。

“下载进度快照与汇总”导出 `workflow.json`、`materials.csv` 和文件哈希manifest，只整理当前记录，不包含原生工程或材料包、不改变旧任务。原包、原CSV和具体执行下载继续使用各原入口。

许可状态仅为现有配置的TCP检查，不能证明实际checkout或设计访问。CPU预览、许可不可连接或原生任务未结束时，下一步会说明限制；最终派发仍由原控制器重新检查。
