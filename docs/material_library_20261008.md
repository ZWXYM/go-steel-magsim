# 材料库与来源入口

在系统首页点击“材料库与来源”，或打开 `/material-library`。选择保存的校准记录，再选择已知样品标定、整牌号留出或预测材料。页面直接读取保存文件，不再次计算校准、预测或原生仿真。

本机实操读回两份校准中的19个材料：8个已知样品标定、8个整牌号留出、3个保存预测。四样品为B23R075、B27R090、B27R095、B30P105。最新记录cal_8fff23daed9e中的B30P105留出与pred_5a6fb5dab354实际使用三样品子库，父库与子库分别显示。未排除样品的预测标为全库预测，不标为材料留出。

下载包括原AMAT、原metadata、原报告、父库与实际有效库；预测还带原输入和prediction.json。材料包另外包含从保存数组整理的当前材料CSV及manifest.json，逐文件SHA256可核对。没有新增拟合、修改原H轴、平滑曲线或重建原生输入。AMAT沿用原导出的(0,0)起点约定，页面CSV保留原保存数组，H固定为A/m，H_scale=1。

已知/留出材料核对原导出AMAT哈希及保存曲线；旧预测没有创建时AMAT哈希，因此核对现存AMAT与保存曲线及原生输入哈希，不声称验证了未保存的历史哈希。父库及有效库的身份哈希是规范化JSON内容哈希；文件表显示原文件字节哈希，两者口径不同。预测必须保存有效库和完整排除范围；缺失、旧格式或损坏条目显示原因，其他完整条目仍可读。不自动重建损坏库、不覆盖旧结果。

当前包为BH-only，kh/kc/ke等零值属于未标定占位，ND为先验。它们可用于材料出口和来源查看，不能直接用于效率求解或最终电机排名。现有库牌号电机扫描沿用电机工作台；作者优化程序、既有结果和工程筛选继续可用。此限制仅对应这些未标定的校准材料。

新增9项测试涵盖保存结果重开、零重新拟合、父子库绑定、完整排除、文件改动、损坏隔离、路径限制、全库预测区分及CPU下载。主全套265项测试通过；网页实操三类条目及完整预测包下载，7个原文件与本机保存文件逐字节一致。19个材料包的清单与内容哈希核对通过，92个现有校准/预测/任务/优化文件读取前后哈希相同。没有新增MuMax、Maxwell或训练任务。
