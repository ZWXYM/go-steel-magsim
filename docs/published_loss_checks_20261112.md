# 工作台中的同牌号实测对照

从系统首页进入“四样品损耗参考”。同牌号发表实测对照可下载复核 JSON 和 28 点的多频图读 CSV。CSV 的单位为 J/kg 每周期，多频复核按频率换算为 W/kg。图读分辨率记录在 JSON；实验未刊出的标准不确定度保持空白。

| 数据 | 测试条件 | 可复核内容 |
| --- | --- | --- |
| B30P105，Zhao 与 Hu 图 9 | Epstein，正弦，B 峰值 0.2、1.7 T | 50–375 Hz 每 25 Hz 读取两条实测虚线。100 Hz 同幅值原电机保存系数分别低约 34% 和 18%。 |
| B30P105，Li 与 Luo 工作簿 | Epstein 700，正弦 50 Hz | 20 个原周期逐点换算 J。J 峰值为 1.5、1.7 T 时的比损耗经表内插值，与宝钢 D.1 的典型值对照。 |
| B27R095，Zhao 等表 4、图 13 | 单片，25 A/m 直流偏磁，4 与 50 Hz | 5 个共同交流峰值的每周期损耗比较，50 Hz 的读值约为 4 Hz 的 1.96–2.16 倍。 |

AIP 表 II–V 的 16 个原表测量和作者模型值也随 JSON 提供，保留 mJ/kg。谐波表未明确列出频率。两项 B30P105 发表实验的试样与方向对应未确认。电机对照复算使用保存的材料系数和均匀正弦公式，电机插片的实际波形需要单独核对。

来源见 [Zhao 与 Hu 的 AIP 原文](https://doi.org/10.1063/5.0020789)、[Li 与 Luo 的工作簿](https://doi.org/10.1038/s41598-024-55155-w)、[宝钢表 D.1](https://ecommerce.ibaosteel.com/baosteel/manufacturerStandard/pdf2023/BQB%20485-2023.pdf) 和 [B27R095 单片原文](https://dgjsxb.ces-transaction.com/fileup/HTML/2020-9-1849.htm)。
