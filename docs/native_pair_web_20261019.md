# 网页原生材料对导出

从系统首页进入材料校准，在“从已有仿真导出原生材料对”选择冻结来源和材料，点击导出。程序读取真实RD/TD table、核对脚本/状态/哈希，保存独立raw_pair.json及来源包；不启动仿真、拟合或预测。CPU模式同样可用。

点击“载入预测输入”，确认校准记录和预测范围，再点击“应用所选范围”。预测结果保留实际排除牌号及有效校准库，可从材料库接续已有批量电机流程。完整排除B30P105时，实际训练材料不包含B30P105。不要把已知样品标定误差当作留出误差。

保存的原生对可从下拉框重开，也可保留页面中native_pair链接；刷新不会重新导出或预测。JSON、来源JSON和完整包均可下载，重开/载入前重新核对保存文件哈希。旧目录、原table和旧预测保持。

主工作区当前盘点9份仿真来源，它们只声明四种材料，并非9种独立材料。成功状态数量只用于盘点，不能替代逐案导出核对或质量评定。当前支持显式branch、cubic_sample_frame_v2、固定物理H及已核验Msat的冻结pilot格式。旧参考修正训练CSV与默认无branch的table尚不能直接转换；不自动重跑失败仿真、不改名重标旧数据。采样协议不匹配时，预测程序会说明原因。
