# 转矩查看保留所选执行任务与检查面板

此前“刷新执行状态”总会选择返回列表中第一份可读结果，即使用户刚通过“查看本材料转矩”选择了另一份结果。相同结果每次刷新也会重新绘制，关闭已展开的保存检查，令读者难以连续核对异常记录。

现在保留当前执行ID。记录增加或顺序改变不影响选择；所选结果未改变时保留曲线、下载和已打开或正在读取的检查。结果内容变化时清除旧检查，防止旧发现对应到新值。所选结果暂不可读时明确显示该执行ID和原因，不自动换成其他结果；恢复可读后回到原选择，也可通过已有按钮选择另一份记录。

只改变页面状态管理，原转矩计算、CSV、结果、诊断、原生执行与参考展示保持。原数值未通过项继续保留其数值与标记，不作删点或重算。真实网页重开DEMO的既有结果、展开六个非正点检查并刷新，任务身份、检查内容和打开状态一致。没有准备任务或下发求解。

Node VM模拟两份结果切换与刷新，旧版两个保留断言为false，修复后均true；覆盖记录新增/重排、所选记录缺失后恢复、结果变化、检查请求跨过相同结果刷新，以及原有当前结果与参考隔离。所有模拟和真实核对均为只读。
