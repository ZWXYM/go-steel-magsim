## 修复的实际使用问题

首页现在提供使用说明入口，读取同一份维护的Markdown，不依赖私有原生工程；说明的联调链接可打开，下载与源文件字节相同。README把旧开发记录折叠，并以当前操作入口为先，保留历史文字和日期。
