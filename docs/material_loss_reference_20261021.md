# 四样品损耗参考入口

系统首页的“校准与材料导出”可打开 `/material-loss-reference`，按样品查看已有资料，无需运行旧分析脚本。可下载四样品JSON、参考点CSV、旧估计CSV或带SHA清单的完整ZIP；读取和选择不生成材料或计算任务。

该页复用 `all_go_core_loss_estimates.csv` 中四种材料的14个原输入点和保存系数，没有重新拟合。B23R075的两个50Hz点来自宝钢EVI手册PDF第5页（印刷04页）；B27R090、B27R095、B30P105的50/60Hz点来自另一宝钢手册PDF第17页（印刷14页）。已逐项目视核对表头、单位、牌号和数值，文档哈希/页码进入快照。

EVI版B27R090的1.5T/50Hz为0.64W/kg，旧估计采用另版的0.63W/kg；EVI版B30P105的50Hz两点为0.74/0.99W/kg，原输入为0.73/1.00W/kg。四个另版点分开列出，未混入原拟合。页面和CSV明确 primary / alternate 角色，这些差异不能当作同一样品的重复测量。

质量系数使用旧程序公式：

`P_W_kg = Kh*f_Hz*B_T² + Kc*f_Hz²*B_T² + Ke*(f_Hz*B_T)^1.5`

Kc由经典薄片公式估计，Kh/Ke来自原非负拟合，磁密指数为2。假定密度7650kg/m³、电导率2×10⁶S/m及质量/体积系数单位单独展示；体积系数=质量系数×假定密度。保留B30P105的Ke=0和B23R075单频分离较弱说明。原RMSE只描述对原输入点的拟合。

这是厂家牌号典型值与现有程序估计，不是本批样品的独立实测；选中表格未单独注明测试方向，快照也不补填RD/TD。未向Maxwell或已有AMAT写入系数，未开启校准B-H分支的效率或最终排名。原作者已有库牌号优化流程保持。完整PDF和原生工程留在私有工作区，公开只有对应事实点、元数据和程序。
# 宝钢标准附录来源对照（2026-11-11）

“四样品损耗参考”另外显示[宝钢标准 PDF 表 D.1](https://ecommerce.ibaosteel.com/baosteel/manufacturerStandard/pdf2023/BQB%20485-2023.pdf)的名义对照，并可下载独立 JSON。PDF 封面是 Q/BQB 485-2023，D.1 所在第 26、27 页（印刷 22、23 页）保留 2022 页眉。源表是厂家典型值，没有逐行的试样、方向和重复记录。B23R075 增加两个 60 Hz 条件的来源证据；相同数字幅值下的 100 Hz 外推仅作为敏感性对照，既有系数及原快照保持。

标准的损耗幅值定义为磁极化 J。在 H = 800 A/m 的 J800 点可以直接用 B = J + μ₀H 换算；其他损耗点未给出配套 H，不能直接当成物理 B。新表对照 V4 保存的四个 RD B800；B23R075 和 B27R090 的拟合值分别高约 0.0504 T、0.0490 T。原拟合对象是日钢/JFE 图谱与单调处理得到的近似曲线，这个厂家单点不验证整条 RD 或 TD，也不把任何版本的拟合当作独立同试样实测。
