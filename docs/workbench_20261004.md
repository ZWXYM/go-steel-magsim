# 四材料校准与电机牌号扫描工作台

用户确认接入 B23R075、B27R090、B27R095、B30P105。入口 `/workbench`，保留原微磁平台并从其侧栏链接进入。

## 启动与操作

论文工作区双击根目录 `start_workbench.cmd`，或在 PowerShell 执行 `tools/start_workbench.ps1`，访问 `http://127.0.0.1:5001/workbench`。公开仓库执行 `python tools/start_workbench.py --port 5001`。只监听本机地址，debug/reloader 关闭。

1. 四个样品默认全选，点击“建立校准并检验”。程序先核验冻结 manifest、原生 script/table 及参考曲线，再生成独立校准记录。
2. 选择材料和 RD/TD，查看原始仿真、参考、标定结果和逐材料留出曲线，下载误差 CSV。“下载四材料校准包”包含 bank、来源报告、所有物理 H/原始/参考/标定/留出 CSV 和四种材料的实验 `.amat`；历史校准可重新加载，旧记录不补写。
3. 上传或粘贴其他材料的 `raw_pair.json`，点击“应用当前校准”，下载物理 H/B CSV、来源 JSON 和实验版 `.amat`。文件需含 material_id、params、simulation_physics_version、texture_sampling_version、RD/TD 的 H/B；H 单位 A/m、B 单位 T。可用 B30P105 示例检查通路。
4. 切换“电机牌号扫描”，选择一个或多个牌号，生成独立任务，再提交队列。各材料顺序求解，自动导出官方报告、整理指标和总结；失败项保留并显示，不能参与通过项排名。

求解时保持服务进程运行。界面关闭不会停止已经启动的求解。服务重启后自动检查队列；页面也提供“检查并恢复队列”。活动或无法确认归属的进程会阻止接管。未执行且冻结源码/副本哈希仍一致的排队任务可按 queued_utc 继续；中断项保留现场，仅通过“仅继续未执行牌号”创建新副本。重新试验已经尝试的牌号仍需另建任务。原锁和恢复前状态留存到 queue_history，OS 文件锁在进程退出后释放，不通过删锁强行启动。

全部新产物写 `data/workbench/calibration/cal_*` 或 `data/workbench/motor/scan_*`，由 Git 忽略；原始来源、旧 bank、模型及电机工程保持不变。校准记录有 bank/manifest/native source 哈希，电机任务有模板、48 个对象、worker 和初始副本哈希。旧失败项也保留。

## 当前校准口径

仍采用 frozen n8 的 `cubic_sample_frame_v2` / `legacy_multi_peak_importance_v1` / `fixed_h_delta_v1`，直接接通现有原生结果和已处理参考；不把新 Haar/prefix v2 输入混入该 bank。历史 raw_pair 缺少采样字段时，仅与四份冻结 JSON 完全一致才补充旧协议及来源 SHA，任意新输入必须自行明确协议。新输入错误版本、非法路径或重复提交会被拒绝。

| 口径 | 平均 RMSE / T | 最大绝对 B800 误差 / T |
|---|---:|---:|
| 原始仿真 | 1.46051 | 1.94831 |
| 四材料标定 | 0.0107405017 | 0.0036523656 |
| 整材料留出 | 0.0658125792 | 0.1590637451 |

RMSE 沿用 H≥100 A/m 的规定非均匀节点等权口径。每次材料留出完全移除该材料两方向的锚点，其参考不回填预测。八条已知材料曲线的 B800 标定误差均小于 0.05 T；留出尚未全部达标。已有 Si 为报告标称值、ODF 为估计，参考为已处理数据，尚无同批次完整成分/EBSD绑定。当前功能提供可审查的修正基准，不能宣称未知材料已经达到相同误差。

导出 `.amat` 保持物理 H，标记实验 B-H，损耗为零占位；不能用该占位材料做正式效率排名。当前电机扫描使用独立的 AEDT 内置材料目录，尚未自动把这些实验版修正材料纳入正式损耗比较。

## 电机模板与指标

选用 V8_2 23ZH90 模板，其 final 版本官方 CSV 与摘要可核验。准备阶段仅改变 48 个 GOES 插片的 MaterialValue；几何文本、对象局部坐标系和激励保持一致。不复制旧求解输出。运行阶段在新独立 AEDT 会话核对每个对象的 `<object>_CS` 和实际材料名，并执行模型验证。

历史单周期对照使用 0–10 ms 的完整 31 点；铁损去首点、铜损保留全部 31 点，沿用 V8_2 指标协议。三周期模式 `periodic_cycle3_v1` 固定 NumTorqueCycles=3，保留 0–30 ms 的全部 91 点官方 CSV；事先规定统计第三周期 20–30 ms 的 31 点，铁损去该窗口首点、铜损全保留。第二/第三周期逐相位转矩差须≤0.1 N·m，平均转矩相对差≤2%、平均铁损相对差≤5%；任一失败则不纳入排名。不能因结果不好再挑窗口或删点。新旧口径各自保存和标记，不能混合排名。

解析实际 s/ms/ns 和 W/mW/kW 单位，转矩和损耗时间网格必须一致。共同通过条件为平均/最小转矩正、最大转矩<10 N·m、脉动<100%、损耗非负；这些条件和周期一致性不能代替网格/时间步独立收敛。效率为 Pout/(Pout+PFe+PCu)，未含机械和杂散损耗。

内置材料及局部 CS 激活不证明完整 RD/TD 张量本构，仍需后续方向验证。历史归档只读取各案 final_resolved 官方 CSV；23ZDKH75 缺失该版本 CSV、27ZDKH85 波动异常分别标记，绝不用另一版本数据补齐。

公开仓库保留程序和限定验证证据，不含完整 AEDT/Motor-CAD 工程或运行环境。若在公开副本运行电机工作台，设置 `GO_STEEL_THESIS_ROOT` 指向本机完整论文工作区；缺失资源时页面明确停用扫描入口。

## 队列恢复与完整汇总（2026-10-05）

页面新增“检查并恢复队列”“仅继续未执行牌号”和“生成完整汇总包”。启动时/提交后以后台检查继续等待活动 worker、许可或专属 Desktop 退出；PID 与创建时间一起核验，未知归属不接管。OS 文件锁防止两个服务进程重复执行。中断时先保存旧状态，再标记待处理；原生结果、旧日志和锁记录均保留。后续任务只复制尚未尝试的牌号，记录父任务与原 manifest 哈希，重复生成会拒绝。

已尝试但状态未落盘的算例保留为待核查，不自动认定成功或重算。改变冻结源码、原副本或模板后不会盲目接续。未确认归属的旧 AEDT 会话仍需核对，不自动关闭任何用户应用。

“生成完整汇总包”重新核验原始 CSV 哈希及保存指标，在任务下的全新 exports/summary_* 目录生成 CSV、Markdown、来源 JSON 和 ZIP。CSV 含测量口径、验收原因、三周期差与有效样本数；ZIP 收录同任务两材料的 10 份官方 CSV、结果/模型验证及 manifest，排除 AEDT 工程和二进制求解目录。新 worker 完成后也直接生成该包；旧汇总保持原样。
