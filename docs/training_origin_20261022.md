# 训练任务来源与工作区恢复

新任务在创建时保存工作区路径和摘要，任务列表/详情均保留创建来源。切换到其他目录后，旧完成任务仍可查询，来源不会被当前目录覆盖。旧任务缺少来源字段时保持未知。

网页等待工作目录确认后才提交或恢复训练，恢复记录按目录分别保存。同目录任务可通过GET恢复；来自其他目录或缺少来源的旧任务只显示历史提示与原任务身份，不展示为当前目录的训练指标。原v1恢复记录保留，仅在服务器确认任务来源后按真实来源建立v2记录，不用当前目录猜测来源。重开、失联查询及历史查看均不自动重训。

回归覆盖中文目录、创建来源冻结、切换后详情/列表、旧任务未知来源、同目录恢复、跨目录历史、存储迁移与保留、初始目录等待、重复操作和任务来源冲突。验证使用临时目录及合成任务；已有模型、任务工程和原始结果不改动。
