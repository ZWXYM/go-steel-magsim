# 主平台工作目录与任务绑定

切换工作目录前，后台检查本进程的活动任务、原生作业、待发队列、流水线及相对路径接口请求；仍在活动时返回409，目录不变。相同目录允许确认并保留输入。空闲切换后清除数据集、模型和流水线实例缓存。

主平台页面把当前工作目录的ASCII摘要绑定到后续接口请求，旧页面不能在另一个页面切换后默默操作新目录。空闲切换成功刷新页面，重新读取该目录的列表与输入；旧文件保留。独立工作台使用绝对资源根，不受主平台目录切换影响。旧客户端不提供摘要仍兼容，但同样受活动任务保护。

回归使用临时中文目录、合成相对路径输出和并发HTTP请求，未改变正在使用的Web目录，也未进行生产训练、材料预测或原生求解。这是同一Web进程内的目录管理；不能约束外部程序直接改变其自身目录。
