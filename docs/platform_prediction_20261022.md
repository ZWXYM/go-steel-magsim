# 快速预测的输入与结果

主平台“快速预测”现在让曲线、复制与材料下载绑定到一次成功预测的模型和参数。修改任一输入后先重新预测；页面显示本次模型和四项输入。刷新模型保留当前有效选择，已消失的模型要求重新选择，旧列表或预测的迟到响应不覆盖新的选择。同一输入正在预测时，多次操作共用同一请求。

复制B-H数据保留RD、TD各自的原始H节点，使用四列 `H_RD / B_RD / H_TD / B_TD`，两方向节点不同不再按同一H错配，零值原样保留。曲线和后台数值算法未修改；页面保留所选模型的H轴口径，旧模型未声明时会明确显示，不因此获得新的物理验证。

.amat下载使用已接受预测的输入快照。提交后的输入修改不改变这次下载的身份，同次导出等待期间只发送一次；HTTP错误显示原因，不把错误JSON下载为.amat。厚度需为正数，错误后可以重试。

原页面脚本已复现“显示A但导出B”、迟到A覆盖B、复制复用A旧缓存。回归使用生产JS、模拟延迟及独立的真实接口数据；包括模型刷新/切换、重复操作、错误恢复、源曲线节点和下载参数。未改原模型、训练、MuMax、电机程序或材料库；没有新材料校准或原生计算。接口和DOM模拟不替代浏览器视觉验收。
