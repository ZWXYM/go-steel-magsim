# 官方电机波形对比

从系统首页、扫描工作台或优化页面点击“官方波形”，进入 `/motor-waveforms`。选择同一模型版本和周期协议，再勾选1至6个已有算例，点击“显示所选波形”。可展示全部周期，或仅显示指标取样周期；鼠标指向曲线查看最近原采样点。

页面显示转矩、铁损、铜损和已有的实心导体损耗，保留负转矩、零值和未通过原数值筛查的波形。失败或缺失官方CSV的算例显示原因，不用原摘要重建曲线，也不借其他版本填补。V8_1的处理结果仍在原优化页面使用。

指标直接复用固定官方CSV程序：单周期31点为0—10ms；三周期91点保留全部原曲线，指标采用20—30ms的末周期31点。铁损去除指标周期首行，铜损保留所有取样行。曲线不平滑、不重采样，模型版本、周期协议或时间网格不同的案需要分别查看。

“下载对比与原始CSV”生成ZIP，包含单位统一为ms/N·m/W的长表、逐案指标/来源哈希JSON及未改写的官方CSV。它只读取已有结果，不启动新求解；下载前再次核对原文件哈希。新扫描还核对冻结结果指标及其CSV来源；旧final版本按既有摘要精度复核。

本轮以3个已完成的新扫描、5个有官方CSV的旧final案实操，另1个旧final缺CSV和1个新原生失败案保持可见。网页下载的2案8个原CSV与源字节一致。重开后已保存的3个扫描、2个自动计划、校准及完整排除材料的预测记录均保留；检查恢复没有重发求解。两个独立CPU进程的中断场景测试只生成未尝试牌号副本并拒绝重复续接，明确为人工CPU流程场景，没有新原生结果。

CPU窗口也可查看和下载。当前主工作区普通实例为 `http://127.0.0.1:5002/motor-waveforms`，保留旧5001进程；双击根目录启动器会核对代码版本并复用相同实例。运行版本现在包含前端JS源哈希。

软件功能验收与材料物理验证按各自记录保留。本轮新增电机、磁静态、MuMax与训练均为0；材料包选择入口仍待整理，论文继续暂停。
