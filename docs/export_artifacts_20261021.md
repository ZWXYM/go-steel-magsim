# HTTP材料导出的独立保存

真实AMAT生成器的合成并发测试复现了同名输出覆盖：A保存后尚未打开下载文件时，B写入同一路径，A实际下载了B的材料字节。预测模型绑定修复本身不能阻止这种文件覆盖。

现在两种HTTP出口（已有B-H曲线、代理预测）都为本次导出分配独立文件名与配套metadata；用户指定的逻辑材料名及浏览器下载名保持。未指定材料名时，自动材料名增加请求标识，避免同秒导出的材料在导入时同名。响应头`X-Material-Artifact`返回本次内部文件名，可与已有导出清单和metadata路径对应。

独立保存以排他创建方式写入；已存在的材料文件或孤立metadata不覆盖，失败保留现场。内部存储名不能包含路径或扩展名。原脚本未指定artifact_name时仍使用原文件路径，校准/预测曲线、AMAT内部名称、物理公式与旧文件格式不变。预测metadata补记实际输入参数，沿用已绑定的模型ID和H轴身份。

测试覆盖同名并发下载逐字节绑定、手工B-H出口保留旧文件、逻辑材料名和默认脚本兼容、文件/孤立metadata冲突、相同请求ID并发排他创建、安全文件名、同秒自动名称及导出清单。测试临时目录与合成数据不进入校准材料库，没有新增原生或训练。

两份已保存代理在普通Web实际同名并发导出通过：各自独立AMAT及metadata、实际模型ID、输入参数和下载字节逐项匹配，11旧导出和12旧模型SHA保持，新增2材料文件与2配套metadata。不发布这些本机检查材料，不据此宣称模型精度改善。
