# 模型目录与当前选择

模型加载和删除只接受单个模型ID，并核对目标就在对应模型根目录内；空ID、父目录、相对/绝对路径及指向其他目录的链接不能成为模型操作目标。常规和候选模型原有目录与命名方式保持。

删除与预测使用同一选择锁：已开始的推理完成后才执行删除，删除当前模型后不会继续默认使用其内存。保存目录已经移除的实例也不能继续作为可用模型推理。删除其他或不存在的模型保留当前选择；失败显示错误并保留状态。保存模型时固定本次目录，数值训练及曲线计算不变。

模型列表保留最后有效读取，迟到读取不能覆盖新记录。每个模型等待删除期间不重复提交，失败恢复操作；成功后刷新列表和预测选择。列表以文本构建，异常记录不会生成可执行的内联操作。

原代码已在隔离目录和完全模拟的删除器上复现：`..`会指向整个数据目录，空ID指向模型根目录，其他路径也会被交给删除器。没有在原资源上执行这些操作，实际删除为零。回归覆盖明确目录、受控目录链接、缓存移除、预测与删除并发、重复按钮和旧列表响应；不删除旧模型或拟合新模型，不改原始数据、MuMax或电机结果。
