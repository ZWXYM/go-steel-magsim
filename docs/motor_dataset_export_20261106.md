# 下载作者原有电机数据集

在“电机优化流程”的“配置工程筛选”中选择数据集，读取成功后可直接点击“下载当前数据集与原文件”。下载只读取保存结果，不需要先保存一份新筛选，也不下发求解或改动旧文件。

每次 ZIP 只对应一个明确的数据集、模型版本和指标协议，包含：

- `dataset.json`：页面实际使用的条目、可选基准、来源哈希及数据范围。
- `metrics.csv`：所有原条目，包括数值异常、缺少官方 CSV 或仅有保存摘要的情况；来源/错误和缺失值保持。
- `accepted_metrics.csv`：原 `input_accepted=true` 条目；筛选不改原判据，不代表新增独立物理验证。
- `reference_choices.csv`：当前页面可选基准，可能与指标条目重合，不能另算作独立实验。
- `sources/`：可读取且哈希匹配的原 JSON/CSV/Markdown。V8_1 包含原处理后的汇总；V8_2 final 仅使用其 final 文件；扫描任务仅使用该任务已记录的文件。缺失的 CSV 不用其他版本补齐。
- `source_snapshot.json` / `manifest.json`：原文件及包内文件哈希、条目数、版本和未包含文件的说明。完整原生工程、缓存、profile 和日志不进入此轻量分析包，仍保留在原位置。

2026-11-06 盘点现有完整工作区：V8_1 为 16 行（14 行通过其原判据）；V8_2 final 为 6 行（4 行通过）；三个旧扫描分别为 1/2/1 行（各 1 行通过）。这些是各自数据集的保存记录，存在重复材料和重复工况，不能相加称为独立样品数。公开副本未附带全部私有电机数据时，以其页面实际可用目录为准。

铁损与效率按原工程报告或估算口径保留，不能因此宣称完成新的独立损耗校准。不同模型、协议或损耗范围的值分别分析。原作者筛选公式、权重、保存排序、计划下发与旧程序均保持。
