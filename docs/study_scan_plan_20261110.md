# 筛选结果自动带入原扫描计划

在约束研究页保存或重开一份筛选后，可在“从所选结果准备复算”勾选可行候选、填写计算核数，点击“准备复算计划与工作包”。程序按原manifest精确匹配库牌号，自动加入同一基准，复用原计划/扫描程序并沿用原配置和测量协议。

准备不开始求解。原优化页仍负责明确开始、串行队列、状态与计算结束后的同任务评分。计划工作包自动登记到现有数据中心，含来源筛选/研究、新计划与任务定义，以及创建时准备状态；实际原生工程在本机新任务目录中。新任务不会复制旧指标作为计算结果，历史版本与新模板也不混拼排名。

同一来源、候选集合与核数重复准备会重开已有计划。模板、牌号索引、worker来源或连接方式改变时，需要刷新来源后再明确选择。零候选、无法唯一映射、基准不同或不支持的历史协议会保留原筛选并说明原因，可回原优化页手动配置。准备失败保留现场，不自动再建任务。

创建时未下发与当前执行状态分别显示；即使原来源目录暂不可读，冻结工作包仍可下载。GPU授权与准备功能无关，实际开始时沿用原程序的资源和许可检查。
