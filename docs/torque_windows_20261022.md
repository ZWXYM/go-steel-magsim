# 批量转矩的自选区间

系统首页进入“转矩区间分析”，或在已有校准材料批量结果点击“自选区间统计与原始点”，选择1至6项和开始/结束时间。默认使用原指标区间；可以收藏批量、材料选择和时间区间，重开后再点击统计。

界面并排显示全段原始点和选中段原始点，悬停查看最近采样值。区间内只使用已有采样点，实际首末点和数量单独列出，不补点、不平滑。均值是采样点的算术均值；峰峰值比为 `(最大−最小)/|均值|×100%`，零均值时不定义。功率按该区间电磁转矩均值乘已保存转速折算，不是铭牌额定轴功率。

原平均转矩、异常说明及原数值判据仍显示。截取后数据变化不会更新原接受标志，不构成新的稳态验证、效率或最终材料排名。比较要求相同模板、模型版本、周期协议、转速与原始时间网格；材料的标定/留出/预测选择及有效库保留。

下载包包含区间统计、全部原始点和入选标志、分析JSON、完整原CSV及SHA清单。来源、区间、选择顺序和已加载的统计程序绑定同一快照；导出时重新核对，不静默下载另一份数据。区间和来源改变后重新统计，失败后原选择可继续调整。

此功能只用GET读取已有结果，不新增求解、训练或预测，不要求许可服务在线；不修改原文件或旧producer。独立回归使用合成CSV，实际接口核对现有四样品单周期结果；浏览器视觉验收另记，不以接口/DOM模拟冒充。

本机实际复验使用现有四样品124个原点：原指标区间与预先指定的索引6至24（从0计，约2–8ms，每条19点）分别统计。下载仍含124点，其中入选76点；4份原CSV字节一致，原判据1通过/3未通过不变。44份原来源文件、16份原执行程序、旧模型与导出资源保持。
