# 保存预测纳入系统工作包

数据中心新增“已保存的材料预测”勾选区，每包最多16份；默认不勾选，刷新保留仍可读取的选择。可以单独收集预测，也可以与校准、已有电机数据、批量和原优化一起收集。不同校准下的预测带各自校准ID，包内分别存放，不能混称同版本优化结果。

工作包V4在 `predictions/<calibration_id>/<prediction_id>.zip` 保存材料库原有完整包，含原输入、父bank、有效子bank、预测JSON、物理H曲线及AMAT/metadata。`data_index.json`列出实际训练成员、排除材料、两个bank摘要和原文件绑定。打包前后核对来源，来源已变化、重复或损坏的记录不登记新包。不调用预测器或求解器。

旧V2/V3工作包仍按原字节读取，旧请求不传 `predictions` 仍可使用。V4表示新的收集结构，不表示新的校准物理版本。完整包留在本机，不自动公开；原始数据与所有旧包保留。整材料排除预测和同材料标定分别说明，零损耗材料不能用于效率排名。
