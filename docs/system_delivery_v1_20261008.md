# 整套系统V1功能验收

本次验收针对可用软件：复用原有微磁平台和作者电机优化程序，打通材料校准、出口、已有库牌号扫描、结果整理、官方波形及工程筛选。没有重写另一套评分规则，没有将旧模型的标量曲线改称新RD/TD本构，也没有把软件验收等同于所有后续物理研究已完成。

## 使用流程

1. Windows双击start_system.cmd，或执行 `python tools/start_workbench.py --open-browser`。默认打开系统首页，核对资源目录和任务存储；占用端口保留，版本不匹配时顺延。默认不自动恢复旧队列。
2. 材料校准打开四个已确认样品的MuMax原生/参考RD、TD，建立或加载保存的校准。新材料上传原生对，可选择完整材料排除；结果记录实际有效库，导出曲线、AMAT和metadata。
3. 材料库直接重开已知标定、整牌号留出、其他预测，查看曲线与来源，下载原文件和完整包，无需重新预测。
4. 电机工作台选择已有库牌号、周期口径、核数，准备隔离任务，明确提交后串行执行。查看每案进度、异常原因，下载官方CSV与汇总。重开服务仍读取原记录；恢复检查保留失败，未尝试牌号可生成独立prepared续接任务，不自动重试已失败案。
5. 官方波形页选择同模型、同协议和同时间网格的1至6案，查看原转矩/损耗采样及指标窗口，并下载对比表和原CSV。
6. 电机优化页复用作者原入口、原数据与原评分。可先配置基准、约束和权重，绑定独立扫描计划，完成后自动整理和筛选；亦可对已有同版本结果重新配置筛选并下载。
