# RD/TD 原表核对

在系统首页打开“RD/TD 原表核对”。选择同时保存拟合和整牌号留出的校准记录与牌号，有配对原表时上传轧向 RD 和横向 TD 两份 CSV。只有一个方向时也可以先比较：将原表上传到对应方向并勾选单方向确认。保存记录只报告该方向，不能据此认定 RD/TD 配对。填写来源或测量记录号，按原资料记录试样、片厚、方法和条件。把需要补查的资料留在“仅归档原表”。

填写原表标注牌号后，系统核对它与选中模型的牌号；不一致时可保留原表归档。原表未注明牌号时，比较页标出对应关系待核对。牌号一致只核对所填标注，试样和测量身份仍由原始记录支持。

比较使用单条初始、直流或正常峰值磁化曲线，分别按发布者记录选择。直流磁化曲线的激励记为直流，频率留空；初始磁化不据此推断为直流。若原表给出 Bm–Hb，Hb 是 B 达峰时的 H，不另当成 H 的峰值。H 须为非负、严格升序或降序。UTF-8 CSV 可使用 `H_A_per_m` 或 `H_kA_per_m`，配一列 `B_T`、`J_T`、`B_mT` 或 `J_mT`。原目录文件中的显式注释表头 `# H (A/m), B (T)` 也可识别。J 按同一行的物理 H 换算成 B。完整磁滞回线使用回线分析流程。

可增加同牌号的第二条校准记录。选“比较并保存”后，全部保存曲线在与上传曲线共同覆盖的物理 H 范围内使用同一组原采样点。误差为保存曲线线性插值的 B 减去上传表的 B。RMSE 和 MAE 等权统计这些点。B800 需要原表与所有选中曲线共同覆盖 800 A/m，页面标明上传值来自原点还是插值。

新核对还报告按物理 H 区间计权的 RMSE 和 MAE。两条曲线都用分段线性插值，在原表及所选模型的节点处分段积分误差平方和绝对值，再除以实际覆盖的 H 宽度。分别给出全共同范围和在 800 A/m 处分开的两段。表中保留实际区间和最大的原表插值跨度；无共同区段则留空。可选填重点区间的 H 起点和终点（如 100–400 A/m）。结果同时保留请求范围与实际共同范围、范围内原点数、用于插值的相邻原点最大间距；没有原点时该区段的积分完全依赖插值。完整原表、全段和 B800 均照常保存。该指标衡量插值曲线，间隔较大时仍须结合原点误差判断。

在结果页展开对照图，可切换 RD/TD 与实际全区间/指定区间。原测量点为实心标记；区间边界的插值点只接线。显示同一物理 H 轴和归档曲线，重合的拟合曲线合并显示。候选页也可按相同区间核对原表与候选。

结果页和数据中心可重开或下载。ZIP 保留原文件字节、原行与派生误差、保存曲线、校准报告和材料文件的 SHA-256、各曲线的训练牌号。来源和配对按上传者声明记入，实验独立性需要原始测量记录。流程联调、图表数字化和厂家参考资料各有来源标签。

实测初始表已确认牌号和方向后，可从保存结果制作“实测区间候选”。候选只覆盖原始 H 两端之间，先做等权最小二乘单调化，再以最多 26 个节点保留变化较快的区段。ZIP 另存原比较包、实际覆盖、选中原行、单调化与重建残差；不给缺测 H 补值，不生成电机材料，也不改默认校准。重建误差不等于对其他样品的验证误差。

## 对照冻结参考表的原采样点

`tools/compare_reference_samples.py` 可一次评估同一冻结试验的多个校准版本。传入工作台存储、原试验目录和两个以上已保存校准编号，首个作为基准。工具核对原表、报告及物理 H 的来源，在共同范围计算未校准的保存集合曲线、拟合与整牌号留出的误差。`comparison.csv` 同时提供 H≤800 A/m 和 H>800 A/m 的点数与 RMSE；可用 `--register` 在数据中心显示 ZIP。该评估的对象是冻结参考，试样独立性仍需另行核验。

```text
python tools/compare_reference_samples.py --storage WORKBENCH_DIR --pilot PILOT_DIR --output NEW_REPORT.zip CAL_BASELINE CAL_CANDIDATE
```

四个基准牌号的八方向共 952 个原采样点。944 点落在共同物理 H 范围，其中 656 点位于 H≤800 A/m。每个版本的拟合误差保持一致。整牌号留出的对照结果如下，完整指标见 `calibration/pilot_reference_samples_20261111/`。

| 校准版本 | 八方向平均 RMSE（T） | 最大绝对 B800 误差（T） |
| --- | ---: | ---: |
| V2 | 0.058472 | 0.106157 |
| V3 | 0.039456 | 0.060356 |
| V4 | 0.024053 | 0.019883 |

V4 相对 V2 的全共同范围 RMSE 在八方向均下降。H>800 A/m 的七方向下降，B23R075 RD 保持一致。误差以同一批数字化来源为对照，新增测量需要单独归档和核验。

在命令中加入 `--field-weighted` 可同时生成 H 区间积分结果，原点口径保持。按八方向等权平均，全共同范围的区间 RMSE 为 V2 0.034119 T、V3 0.031351 T、V4 0.015937 T。V4 全共同范围八方向均下降；低场至 800 A/m 的 B27R090 TD 从 V2 的 0.035865 T 上升到 0.052438 T，其他七方向下降。此处是既有数字化参考的口径敏感性，默认模型和四牌号结果保持。见 `calibration/reference_field_weighted_20261112/`。

可用的同牌号出版实测例：[ICS TEAM Problem 21e](https://www.compumag.org/wp/wp-content/uploads/2021/04/problem21_inputdata_P21e.pdf) 的宝钢 B27R090 RD/TD 数字表，初始、直流与正弦峰值分别核对。初始 TD 在 155.45–400 A/m 的 V2/V4 整牌号留出区间 RMSE 为 0.7720/0.7308 T，明显大于既有目录代理误差；实测表以下无外推。见 calibration/compumag_p21e_b27r090_measured_20261112/。
