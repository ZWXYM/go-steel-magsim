# RD/TD 原表核对

在系统首页打开“RD/TD 原表核对”。选择同时保存拟合和整牌号留出的校准记录与牌号，上传轧向 RD 和横向 TD 两份 CSV。填写来源或测量记录号，按原资料记录试样、片厚、方法和条件。把需要补查的资料留在“仅归档原表”。

比较使用单条初始磁化曲线或正常峰值磁化曲线，H 须为非负、严格升序或降序。UTF-8 CSV 可使用 `H_A_per_m` 或 `H_kA_per_m`，配一列 `B_T`、`J_T`、`B_mT` 或 `J_mT`。原目录文件中的显式注释表头 `# H (A/m), B (T)` 也可识别。J 按同一行的物理 H 换算成 B。完整磁滞回线使用回线分析流程。

可增加同牌号的第二条校准记录。选“比较并保存”后，全部保存曲线在与上传曲线共同覆盖的物理 H 范围内使用同一组原采样点。误差为保存曲线线性插值的 B 减去上传表的 B。RMSE 和 MAE 等权统计这些点。B800 需要原表与所有选中曲线共同覆盖 800 A/m，页面标明上传值来自原点还是插值。

结果页和数据中心可重开或下载。ZIP 保留原文件字节、原行与派生误差、保存曲线、校准报告和材料文件的 SHA-256、各曲线的训练牌号。来源和配对按上传者声明记入，实验独立性需要原始测量记录。流程联调、图表数字化和厂家参考资料各有来源标签。

## 对照冻结参考表的原采样点

`tools/compare_reference_samples.py` 可一次评估同一冻结试验的多个校准版本。传入工作台存储、原试验目录和两个以上已保存校准编号，首个作为基准。工具核对原表、报告及物理 H 的来源，在共同范围计算未校准的保存集合曲线、拟合与整牌号留出的误差。`comparison.csv` 同时提供 H≤800 A/m 和 H>800 A/m 的点数与 RMSE；可用 `--register` 在数据中心显示 ZIP。该评估的对象是冻结参考，试样独立性仍需另行核验。

```text
python tools/compare_reference_samples.py --storage WORKBENCH_DIR --pilot PILOT_DIR --output NEW_REPORT.zip CAL_BASELINE CAL_CANDIDATE
```

四个基准牌号的八方向共 952 个原采样点。944 点落在共同物理 H 范围，其中 656 点位于 H≤800 A/m。每个版本的拟合误差保持一致。整牌号留出的对照结果如下，完整指标见 `calibration/pilot_reference_samples_20261111/`。

| 校准版本 | 八方向平均 RMSE（T） | 最大绝对 B800 误差（T） |
| --- | ---: | ---: |
| V2 | 0.058472 | 0.106157 |
| V3 | 0.039456 | 0.060356 |
| V4 | 0.024053 | 0.019883 |

V4 相对 V2 的全共同范围 RMSE 在八方向均下降。H>800 A/m 的七方向下降，B23R075 RD 保持一致。误差以同一批数字化来源为对照，新增测量需要单独归档和核验。
