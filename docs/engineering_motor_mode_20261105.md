# 校准曲线的电机工程比较

材料库和校准材料批量页新增 RD 等效、TD 等效两种单周期模式。它们分别把保存材料的一条方向 B-H 曲线作为标量材料，沿用 V8_2 几何、3000 rpm、原电流、48 插片和原定转子损耗对象，生成独立工程及官方转矩 CSV。所有源 H/B 节点保留，原 RD/TD 张量材料也保留在工程中。

这个模式适合比较不同牌号在同一等效假设下的转矩和脉动。它不表示真实取向硅钢在所有方向具有相同性能，也不验证插片转角的作用。需要研究局部方向时，仍选择 RD/TD 张量诊断模式。两类结果有不同协议与模型版本，不混作同一模型的材料差值。

RD 等效模式已在一个独立 B30P105 对照中实际完成，使用 cal_8fff23daed9e 的同一条 26 节点 RD 曲线：

| 保存结果 | 平均转矩 N·m | 最小转矩 N·m | 最大转矩 N·m | 脉动 % | 原数值判据 |
| --- | ---: | ---: | ---: | ---: | --- |
| 原 RD/TD 张量单周期 | 5.767007 | -20.684312 | 177.377465 | 3434.394569 | 未通过 |
| 新 RD 标量等效单周期 | 1.878306 | 1.457529 | 2.120323 | 35.286794 | 通过 |

此对照说明同一源曲线可在方向等效模型中产生合理的转矩波形，不能据此认定原张量分支的异常原因已全部解决。比较保留全部 31 个官方采样点，没有删点或平滑转矩。TD 等效与其他材料的实际执行结果按各自任务记录列示，不能把这一份 RD 结果扩大为所有模式已通过。

正式队列的 B27R095 非平滑 RD 等效结果随后完成，平均转矩 1.897899 N·m，但最小 -1.084580、最大 6.324258 N·m、脉动 390.370400%，未通过原判据。因此没有据 B30 单案扩大四材料计算。新增的“平滑/迭代对照”使用独立协议和模型版本，保留原节点/时间步/判据，在求解器内启用 B-H 平滑并显式设置非线性迭代 1–100 次；逐项核对实际保存设置后才求解。它是待实际验证的数值设置，不把准备完成当作结果改善，也不改变旧单案的数值或接受状态。

两种等效模式继续提供 B-H 材料的转矩与功率折算。损耗系数仍为未标定的零占位，因此不生成这一路径的效率或最终效率排名。作者原材料库的优化程序与历史结果继续使用。

新任务在保存、运行和下载中保留原材料名称、实际等效材料名称、来源方向及协议。新服务通过源版本检查后才能下发；旧结果和失败目录可继续查看，不重新执行。连接 AEDT 时还从原生 API 核对实际 PID，避免把客户端请求 PID 当作已经接入目标会话。

开发者可在启动服务前用进程环境变量 `MAGSIM_AEDT_TRANSPORT=auto|grpc|com` 选择连接方式；新任务冻结该选择，旧任务默认 auto。它不修改本机许可配置或其他应用设置。COM 兼容方式仅在必要的本机兼容场景使用，实际工作区仍由 PID、创建时间和独立工程范围核对。

第一份对照的完整原生工程和初始化现场保存在主工作区 `work/core_results_20261105_190535/`。首次 gRPC 初始化失败、随后 COM 接入及实际 PID 校正记录均保留；这两次实际 Desktop 创建如实计数，不把“未新增启动”的原计划当作实际记录。后续系统内执行和限定公开的 CSV 见动态交接与发布证据。
