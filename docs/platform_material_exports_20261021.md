# 主平台AMAT导出记录

从系统首页或校准材料库打开“主平台导出记录”，浏览当前工作目录 `data/exports` 内的原AMAT，包含子目录。可按材料名/文件名/模型筛选，收藏选中条目，下载原材料、原metadata、带SHA清单的ZIP和当前目录CSV。所有操作只读，不重新预测、导出或求解。

优先显示原配对metadata的模型、参数、H轴；未记录的值保持空缺，不根据Pred文件名猜模型。历史增强材料精确匹配同目录augmented_metadata.json的aug_name，显示源记录并保留原目录文件，增强数据不标为独立实测。损坏metadata、仅有metadata或单个文件不可读时，该条目保留说明，其他记录可用。

条目ID绑定当前绝对目录、原文件和metadata字节哈希。文件或工作目录变化后，旧链接拒绝改绑到其他内容；目录CSV也绑定显示时的快照。ZIP使用一次读取的同一组原字节，包含entry.json及SHA清单。

这批文件作为既有平台出口查看；校准材料库中已有的21条标定/留出/预测记录和电机准备入口保持。新页面不把旧出口自动加入校准库或电机队列，也不重写来源、曲线或损耗。
