## 固定方法和预算

保留现有8个候选，再加入3个beta=0.25的f_Goss仿射残差候选，ridge为1、0.1、0；总计11项。beta是工程残差保留系数，不是物理贡献比例。每个外层完整移除一个材料的RD和TD，再只用其余三个材料进行内层材料留出，按等材料/等方向的RMSE(H>=100)+|B800误差|选择。外层参考只用于预测完成后的指标计算。仅参考内插beta=0仍不作为候选。

物理H节点、Msat/单调J约束、f_Goss尺度0.1和带符号权重L1上限3均不变。预先规定：平均RMSE至少下降10%、最坏B800/方向RMSE不增加、任一方向RMSE回退不超过0.01T、全部B800<0.05T；最后一项未通过。不能在这次外层误差上继续反复改候选并称独立验证。

预算上限420次小样本预测评估/60秒CPU，本次340次约0.13秒。四外层均选择beta=0.25：B23R075和B30P105为ridge0.1，B27R090和B27R095为ridge0。逐项指标、全部内层划分和候选损失保留。反事实修改任一外层材料参考的RD/TD时，其选参和预测不变；该材料自己的数据不进入其训练权重。

## 复现

在公开仓库目录执行，输出必须是新目录：

```powershell
python tools/run_calibration_beta_trial.py --bank calibration/generalization_20261005/cal_65e506f6e207/bank.json --output-dir calibration/new_beta_trial
```

本机也可指定保存的cal_8fff23daed9e/bank.json。工具在读取目标数据前写入冻结协议，核对bank/report及输入哈希；输出只有协议、来源、开发结果JSON和指标CSV，不写bank或AMAT，不训练、不下发求解，已有目录拒绝覆盖。原型与整理后的程序在本机得到完全相同的8条试验曲线。六项专项测试覆盖全部外层反事实、预算、接受门限、来源一致性和不覆盖行为。

程序仅供该冻结研发对照，未接入系统默认材料出口。旧数据与正式使用入口保持。成分与织构独立作用、未见材料/新批次、回线及损耗验证仍需要其他证据。
