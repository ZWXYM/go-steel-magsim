# 校准材料原生导入入口

在 `/material-library` 打开已有标定、留出或预测材料，从保存的 `calmotor_*` 点击“准备原生导入”，再手动点击“执行原生导入与预检”。准备与原生执行分开；CPU 预览只允许准备，普通窗口才允许执行。刷新状态或重开页面可以读取保存记录，不重新预测、不进入扫描队列。

子目录 `calibrated_motor_native/calimport_*` 保留父准备 manifest、原包、实际训练库、AMAT、metadata 和输入工程字节。执行前检查文件及程序哈希、现有许可 TCP 和其他活动任务；缺少许可时保持 ready，不启动 AEDT。执行痕迹存在的记录不允许重新执行，失败副本全部保留。

专用 worker 的范围是：以 `NAME:Point` 导入 RD/TD，读取实际保存的节点，赋值 48 插片并保留其 CS，保留原定转子损耗对象并选择全部插片，运行原生模型预检。只有这些步骤通过才显示 imported_not_solved 并提供已保存工程及 summary 下载。不会调用 Analyze，不计算效率，不生成优化排名。零损耗占位并未因此得到损耗标定，CS 引用保存也不代表新增方向物理验证。

预算为 1 专用会话、0 磁场/电机求解、240 秒。超过预算时标记需检查，不终止未知或用户进程，不自动重试；仅凭创建时间确认属于本 worker 的会话可以通过原生 API 释放。
