# 校准记录、预测输入和下载来源绑定

以前预测等待返回时切换校准，下载链接会使用返回时的current校准ID，而预测实际保存在请求发起时的目录。使用已有预测只读核对：正确目录的CSV返回200，拼到另一个校准目录返回400；文件本身未损坏。此前快速切换校准的迟到读取也会覆盖新选择，重复点击能产生两个预测请求。

现在请求固定校准ID、原始输入和排除范围；返回须符合请求的校准/材料/预测身份。下载地址始终从固定来源构造，结果同时显示校准和预测编号。等待期间换库或改输入，先前预测不会混到当前结果区；完成后提供从原校准材料记录重开的链接。当前请求未返回前不重复预测，校准建立也保持单次请求。

切换或清空校准时解除旧报告和预测操作，加载失败或身份不符不继续使用旧库。校准读取、清单刷新及新建记录都区分请求先后和当前选择；较早配置生成的记录仍保存，但不会覆盖用户后来选择的记录。输入文件、示例和原生对使用同一输入更新入口，旧文件/示例的迟到返回不能覆盖较新的输入。

主工作台脚本与原生对、冻结研发预览按原顺序延迟加载，保留它们的现有接口。已保存两份校准的16张图、误差及质量表与原页面逐项相同；已有预测的五个正常下载地址完全相同。原校准/预测后端四文件、参考数据、bank和原生table均未修改。

真实网页只重开已有校准、切库、载入已完成的DEMO原生对及打开冻结研发预览，没有建立校准或保存预测。测试的POST是Node VM模拟响应，实际新增记录和原生下发为0。不能把界面状态修复称为材料精度变化，所有旧结果和研究范围保持。
