# 从约束研究接回原优化

打开“原优化约束敏感性”中的保存研究，在“应用一组研究条件”明确选择一组配置，点击“按此配置保存筛选”。程序核对当前数据与该研究的冻结来源，调用原优化程序建立独立筛选。完成后可查看原优化结果、下载排序CSV或包含原研究和分析的完整包。

同一研究、配置和文件来源再次应用会重开已有记录，不重复筛选。来源或原评分版本已变化时需建立新研究；异常、中断和失败保留，不自动重试。新的工程筛选不启动电机扫描、代理训练或材料预测。进入原优化结果后，可用已有“沿用配置”功能继续配置扫描计划；实际提交仍由原入口明确执行。

原默认配置及默认下零候选的结果保持。允许转矩下降等容差的结果只适用于所选条件，不能代替原默认结论。原评分函数和作者原程序不修改，旧研究与优化记录不覆盖。配置记录不增加独立材料数，也不是新的电机物理验证。

保存结构：`application.json`列出研究、配置、基准、源摘要和新原筛选ID；`study_bundle.zip`保留原研究六文件；四个`analysis`/`ranking`文件保留本次原优化出口。新记录可在源数据暂不可用时重开，文件或摘要不符会明确报错。

实际接口验收使用已有V8_2同报告六案数据：原默认c33仍为0候选；显式选择c30（脉动至少降30%、转矩变化至少−0.5%、铁损最多增0%）得到23ZDKH75这1个候选。相对同源M6基准，原指标为转矩−0.15885%、脉动−42.2071%、铁损−2.39815%，没有新求解。该原库比较与四样品校准材料的结果分别保存；两次请求及重开没有改变旧评分、默认或数据。薄证据见 `calibration/study_application_20261109`。
