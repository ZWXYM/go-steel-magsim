# 批量页的记录切换与材料勾选

已修复两个可复现的操作问题：

- 刷新材料以前会清空勾选。现在同一校准记录下保留仍可用的材料键，已不可用的条目移出勾选；切换校准记录仍清空选择，避免把相同材料键套到另一个bank。
- 以前切换已保存批量时，在异步读取完成前旧记录和操作按钮仍有效，模拟点击能产生发往旧批量的开始请求。现在切换即清除旧操作绑定、旧结果和下载链接，加载期间开始/接续/暂停均锁定；成功核对返回批量身份后才恢复。

读取失败、指定记录不存在或返回身份不符时，旧结果及操作保持清空；旧批量的迟到响应不能覆盖当前选择。一个动作等待返回时不接受第二次提交，刷新材料也不能重新启用其按钮；动作失败信息只显示在对应批量，切换到另一批量后不混入。

这些是网页状态修复，不修改后端任务、队列协议、求解预算、校准bank、原始转矩或既有判据。准备计划和原生执行仍是独立按钮，失败任务不会自动重试。刷新仅保留当前页勾选，不跨浏览器重开自动提交。

修复前用原页面脚本与Node VM模拟网络复现：刷新后1个勾选变0，切换期间模拟点击产生1次发往旧批量的POST；实际网络/原生下发为0。修复后同样对照保留1个勾选、切换期间模拟POST为0。前端回归覆盖延迟读取、跨批量迟到响应、缺失/读取失败/身份不符、待返回重复操作、材料失效和跨校准隔离；实际网页验证四个勾选经刷新仍保留。旧存储、原作者优化与全部科学输出不变。
