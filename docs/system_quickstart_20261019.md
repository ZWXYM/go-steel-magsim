# 系统操作速查

双击主工作区的start_system.cmd。启动器保留已有应用，选择匹配版本或新端口；以首页显示的资源目录和任务存储为准。公开副本使用自己的start_system.cmd，也可指定--root和--storage接入现有资源。新启动默认不恢复旧队列。

1. **校准与预测**：从首页进入材料校准。加载保存校准，或勾选B23R075、B27R090、B27R095、B30P105建立记录。查看标定与整牌号留出；上传其他材料原生对后保存预测、下载曲线和材料包。
2. **校准材料批量分析**：进入同名页面，选择校准记录，勾选标定、留出或保存预测（1–8种）。准备计划只做CPU工作；查看预算后点击开始，实际导入、工程复制和转矩分析自动串行推进。已有结果直接复用，原始材料和来源分别保留。
3. **暂停与重开**：请求当前阶段结束后暂停；保留本批量网址，重开后显式接续。当前原生阶段不会被杀掉，已完成导入/求解不重复。失败和超时保持可见，不自动重跑。
4. **原库牌号与优化**：从电机工作台选择既有牌号并准备/提交；优化页复用作者基线、约束和评分。可浏览旧结果、官方波形并下载原CSV及汇总。校准B-H转矩分支没有独立损耗，不补效率或最终材料排名。
5. **结果与异常**：批量页显示实际转矩、原始点叠图和下载包。进入独立分析页，点击“查看异常与求解记录”，可看到非正转矩时刻、前后原值、匹配profile的原字段和保存设置；也可下载检查摘要。检查不启动求解，不删点/平滑，不改变原数值判据。

本机实例bhbatch_3d20d4726b94包含一项结果复用和一项B23R075真实完成。B23在3.333333ms有负点，已在页面/摘要标记；检查尚未确定原因。保存设置相同不证明真实材料或非线性收敛相同，profile的Final Residual与设置残差未直接等同。完整工程/profile留在私有工作区，公开仅程序与薄验证记录。
