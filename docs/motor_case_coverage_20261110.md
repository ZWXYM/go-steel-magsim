# 逐案例数据覆盖清单

数据中心可下载“逐案例数据清单 CSV”或同内容的JSON。每行保留原数据集、模型版本、测量协议、案例、材料名称、原接受状态和四项原指标，附官方CSV路径/哈希及内容组。不同版本只并列清点，不混拼优化排名。

当前范围是数据中心的原库/扫描优化数据集；校准材料的B-H转矩批量继续使用各自批量报告，不混入这份清单。保存行数对应原数据集rows，单列的基准选择不再重复加为一条结果。

内容组按该案例完整CSV哈希多重集计算，文件改名不增加一份内容；缺少CSV的记录不分到同一个空组。相同内容只说明文件复用，不能推断试验或材料是否独立；不同内容也不自动视为独立实测。历史处理/估算、失败行及零值均保留。

清单从已完成任务和旧归档只读生成，不创建新结果或筛选。单项数据不可读时，其错误留在清单，其他完整数据仍可下载；JSON的counts.complete为false。CSV单位由列名标注，效率仍沿原估算范围。原数据集下载包含原始文件，覆盖清单用于定位和选数据。
