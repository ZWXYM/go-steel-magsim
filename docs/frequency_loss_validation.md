# 多频损耗留出复核

在系统首页进入“多频损耗复核”。每次选同一试样、同一方向和同一统计版本的 UTF-8 CSV。填原表来源、试样标识及预先选定的留出频率。每种峰值至少三档频率，留出频率须夹在其他频率之间，例如有 50、60、100 Hz 时可留出 60 Hz。已知的试片配置可逐行记录；有配置变化时，误差适用于原表的组合条件。

| 项目 | 表头 |
| --- | --- |
| 频率 | `frequency_Hz` |
| 峰值，二选一 | `peak_B_T` 或 `peak_J_T` |
| 损耗，二选一 | `specific_loss_W_per_kg` 或 `volume_loss_W_per_m3` |
| 每周期能量，可替代功率损耗列 | `specific_energy_loss_J_per_kg` 或 `volume_energy_loss_J_per_m3`；可用对应的 `standard_u_J_per_kg` 或 `standard_u_J_per_m3` |
| 实测峰值，可选 | `observed_peak_B_T` 或 `observed_peak_J_T`，与分组峰值的量一致 |
| 标准不确定度，可选 | `standard_u_W_per_kg` 或 `standard_u_W_per_m3`，对应原损耗单位 |
| 逐点试片配置，可选 | `configuration` |
| 原表身份，可选 | `sample_label`、`direction`（`RD`、`TD`、`other` 或 `unspecified`）、`table_variant` |

B 与 J、质量与体积单位分别处理，不互相换算。使用每周期能量时，按行乘以频率（不确定度同样换算），原值保留在上传文件及核对记录；结果以 W/kg 或 W/m³ 报告。有实测峰值列时，填相对分组峰值的允许绝对偏差。超差则拒绝保存；区间内按上传的分组对照，保留每个实际峰值，不做峰值插值。可直接读取附带的 HEFMAG 第 20 页 CSV，识别 `peak_polarization_J_T`、`specific_power_loss_xref_W_per_kg`、`reference_u_W_per_kg` 和 `nominal_strip_configuration`。同一峰值和频率不能重复，混合试样、方向或统计版本须拆表。留出频率上的损耗值和不确定度只用于对照。

每个峰值均列出最低频损耗的正比换算，以及留出点两侧最近训练点的每周期损耗线性插值。训练频率至少四档时，另拟合非负频率基函数 `f`、`f^1.5`、`f^2`，以该峰值的最高训练频率缩放。训练点都有标准不确定度时，最小二乘残差除以各点的不确定度；缺少时用等权。训练频率不足时，报告保留原因，拟合值和系数留空。误差是预测减原值，相对误差除以留出原值。原标准不确定度随表提供，不充当拟合预测的不确定度。

结果可在数据中心重开或下载。工作包包括逐字节保留的原表、每点来源与训练/留出角色、系数与误差表。多频结果不写回材料库或电机损耗系数。

已有单周期核算时，也可打开“从保存回线复核”。选择至少三档不同频率、同一来源和试样、同一方向、方法与共同条件的回线。每档频率只选一条；不能用同一个原文件重复标频。指定原 B 或 J 目标峰值与允许绝对偏差，系统用每档实际峰值筛选；按 W/kg 时各档必须具有相同且有来源的密度。工作包记录整理表、每档真实峰值和闭合段贡献、原回线 ZIP 和试样声明。这条路径的频率表来自已保存积分，缺少原测量不确定度时不补值；系统不会独立认证试片身份或驱动波形。

原表核对、回线核算与多频复核均可在 CPU 分析模式保存。它们只读取或整理测量数据，无需启动原生求解或训练。

已用 Michal Ulvr 的 [HEFMAG 报告](https://doi.org/10.5281/zenodo.10032756) 第 20 页原统计、四个 J 峰值及五档频率核验，复算文件见 `calibration/frequency_loss_workbench_20261112/`。第 22 页另列的替代统计在 `calibration/frequency_loss_sparse_20261112/`，用 200 和 1000 Hz 对照 400 Hz。两表分别归档，配置随频率变化；留出结果是该试样的表内对照。本例没有绑定项目的四个牌号。

[Silva 等发布的无取向钢损耗表](https://doi.org/10.17632/hgzgpcvjxk.1)以 J/kg 发布。以同一 RD 试样、0 MPa 的 1/50/100 Hz 共 80 个原点复核：72 点按实测峰值组成 24 个三频组，保留其余 8 点；1/100 Hz 留出 50 Hz 的双侧插值平均绝对相对误差 2.99%，最低频对照 31.50%。原始磁密与分组峰值的最大差为 0.002033 T，未用磁密插值。不适用于本项目四个取向牌号。见 calibration/nog_rd_loss_table_validation_20261112/。
