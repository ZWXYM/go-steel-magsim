# 空气界面独立方向响应（2026-10-07）

三个限定预算对照全部达到预定控制目的：显式单位轴向量 object-CS 与 relative-CS 同时通过独立 B、原生总能量和官方自适应收敛；忽略方向的 Global 负对照完成并收敛，但未匹配制造解。现在有证据确认该常磁导率新 coupon 的方向实际影响求解中的磁場响应。真实非线性材料、全部48旧插片方向以及完整 H 导出接口仍未认证。

## 冻结模型与结果

20×20 mm 双区域模型，左半各向异性 μr=[1000,100,1000]、右半空气 μr=1，深度1m。左材料框架采用来源 GOES_V3_02 的绝对端点候选47.3326°，新object-CS写入正交单位方向向量，未修改原电机CS。解析解固定法向 Bx 连续、切向 Hy=0；左侧 By≈0.02195611388 T，Bx≈0.02513274123 T。全局 Az 分段表达式仅施加六个外边，两个共享界面边不施加边界。

|---|---:|---:|---|---|
| 显式 object-CS | 1.93e-8 / 1.80e-8 | 7.73e-6 | 通过 | 正对照通过 |

冻结门限：B绝对误差1e-4 T、均匀性1e-3相对值、能量1e-4相对值、官方能量误差与变化均≤0.1%。负对照必须实际完成且收敛，B不匹配才能作为有效排除；失败或缺失数据不算成功。最大3项串行，2CPU核、0GPU、每项120秒、最多6pass，不重试旧目录。外边顶点、共享边排除、SI探针、材料各分量、1meter深度、空间表达式与原生预检已实际核验。

Ansys 官方文档允许二维磁静态向量势边界使用空间函数并指定坐标系；本轮另用实际保存和成功求解核对 `min(X,0meter)` 的本机执行，而非仅凭 API 返回值。[官方向量势边界说明](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Maxwell/Content/Maxwell/AssigningaVectorPotentialfora2DMagnetostaticSolver.htm)

## H 导出矛盾保留

两个正确方向控制中的材料 H 导出均值仍约 [20,174.7212,0] A/m，与把全局 B 直接代入未旋转对角张量的候选相符（最大相对差约7.9e-7）；与实际方向张量的候选相对差约4.51。独立 B 与原生总能量支持旋转求解响应，H 字段矛盾仍待查明。本轮 H 保留为原生诊断数据，没有用解析重建 H 替换原生结果，也未将 B 控制通过称为完整接口通过。

`native_v2` 的首次开发准备在场求解前因 AEDT 背景材料不存在错误停止，实际求解0，完整失败记录保留。新的 `native_v3` 改为核验默认保存的单位深度，在材料创建前不改设计设置；异常消息捕获和独立会话释放使用嵌套 finally。v2遗留的专用PID经创建时间核验后通过原生API关闭，仅处理本任务创建的会话。全部4个本轮新专用会话已释放，未关闭用户应用。

私有原生目录 `calibration/diagnostics/air_interface_20261007/native_v3`，薄证据 `calibration/air_interface_20261007/native_v3` 含冻结 producer、六外边预检、18点 B/H、官方逐pass收敛、原生定义摘录、CPU reviewed_summary。完整工程、缓存、profile、日志仍私有。

累计 Maxwell 完成39=4电机+35磁静态，MuMax680。新增磁静态3、电机0、MuMax0、训练0；校准bank和材料留出误差保持，1465项旧来源/检查点、五扫描状态、525pilot及26冻结校准文件保持。主工作区初始184/185测试检查点保留，增加系统vacuum省略字段与已保存方向向量的严格核验后重新验证186项测试；公开副本另行全套验证。

保存的 `vacuum` 是未修改的 `Materials/SysLibrary` 引用，AEDT省略默认 permeability/conductivity 字段。CPU审计仅在该明确库身份、未修改标志且无非标量覆盖时接受系统默认 μr=1/σ=0，任意其他缺字段材料均不套用默认值；空气原生B/H和总能量原样保留。没有把省略字段称为明确写入的标量证据。[官方2025R1材料属性说明](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v251/en/PDFs/MaxwellScriptingGuide.pdf)

下一步先对全部48旧CS建立显式向量候选与几何主轴绑定的隔离模板准备，单一47°控制不能替代全覆盖；另用恒磁导率非线性B-H表示与简单张量表示作配对假设，查明真实曲线的插值/残差。保持源26点不变、真实非线性门限不变，之后再接正式电机。零损耗材料仍禁止效率求解，最终排名保持不可用。

新object-CS在保存后保留有长度单位的X方向，同时将Y轴保存为无量纲单位向量。审核比较归一化方向，并拒绝混合非零有量纲/无量纲分量、非单位的无量纲轴、反向和错误方向；不把无量纲Y轴假定为米制端点，也不据此改写旧48CS。原生响应和门限保持。
