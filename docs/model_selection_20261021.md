# 并发代理预测与材料出口的模型绑定

原接口共享同一个可变BHPredictor：请求A选择模型后，请求B可以在A推理前加载另一模型。确定性的两线程测试实际复现了A返回B的曲线与H轴身份。预测后导出材料也复用了这条路径。

现在模型选择和推理在同一次互斥操作内完成。指定模型加载到候选实例，成功推理后才成为默认；加载或推理失败不会破坏上一个可用实例。后台常规训练用独立实例计算，成功后一次发布，不在训练期间逐个改写推理字段。训练计算期间已有预测仍可用。训练方法、数据筛查、模型文件格式和权重不变。

省略model_id仍使用最近一次成功的默认模型；预测响应记录实际model_id，材料出口沿用该身份，修复省略model_id时原材料metadata记录空来源的问题。对旧模型不补填新的物理版本或校准身份。

并发预测、预测/导出交叉、部分加载失败、推理失败、训练期间预测、训练失败、训练下发回调与隐式默认出口均有专项覆盖。测试使用隔离的替身和临时文件，不启动训练或原生求解。真实旧模型另外只读比较，不把并发修复称作材料预测精度改善。

批量准备文案同时改为“生成或复用任务，实际分析需单独开始”，避免把准备操作理解成全局GPU限制。普通模式的原生与训练授权保持。

另用已保存的常规/选优代理各做直接与HTTP预测：常规模型逐值相同，PCA ExtraTrees并行归约的RD/TD最大差2.22×10⁻¹⁶T，全部1952数值在1e-12计算舍入容差内，H节点与来源标签一致。原12模型文件SHA保持，无重训练。初次逐位float相等检查失败后，只增加一对并保存完整数值复核；这不是放宽材料误差门限或更新模型。
