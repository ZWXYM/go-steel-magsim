本次只修网页的请求和显示状态。作者原评分函数、六个程序入口、历史指标及所有保存结果不变。

以前保存数据集A的筛选尚未返回时切到B，A的迟到结果仍会显示在B的控件下；刷新结果清单等待返回时，用户新选B也可能被反选为A。现在筛选请求固定当时的数据集、比较基准和六个配置值；返回身份与请求必须一致，当前选择已变更则只提示已保存到历史，不把旧结果叠到当前页面。修改约束、权重或基准会隐藏旧结果，重新保存后再显示。

同一计划提交等待返回时阻止第二次请求，轮询重新绘制也保持该按钮禁用；CPU模式不提交。建立或关联计划也保持单次请求，准备与原生提交仍分开。改变网页状态不会自动生成计划、重试失败或开始求解。
