# 可选低微磁权重校准版本

网页校准方法新增“低微磁权重开发候选”。选定后可生成独立校准、进行其他材料预测、排除完整材料后重新训练选择，并导出 RD/TD 材料和数据工作包。原默认 V2 保留；不带记录参数打开工作台时不会自动采用这个候选。材料库和数据中心显示模型名称，显式打开记录会同步选择对应的方法。

算法版本为 `fixed_h_regularized_transfer_v3`。在 V2 八候选上加入三种 ridge、微磁残差权重 beta=0.25 的候选；每个外层材料留出仍只用其余材料做内层选择。预测排除材料时重建同版本子 bank 并重新选择，不能沿用全材料选择结果。已知材料的标定曲线和物理 H 轴保持不变。

这是冻结低权重试验的工程接通，使用相同四个开发样品，不能称为新的独立外部验证或成分效应已识别。四材料八方向的208行曲线、48行误差包含不同处理口径，并非新增独立样品。V3报告额外保留原 V2 整材料留出对照，网页和CSV均可比较。新版本没有改善或重新验证损耗。

已实际生成、下载并重开校准/材料库/数据中心。校准工作包16成员，预测材料包9成员；bank/report/材料字节与保存来源一致。不同出口的CSV字段名按各自既有协议保留，逐行映射后数值一致。校准默认记录仍为原 V2。11项新增专项测试覆盖完整材料隔离、被排除参考曲线反事实、版本重载、导出和目录默认行为。

材料是零损耗占位的 B-H-only 出口；不能据此计算效率排名。该版本没有新增物理求解或代理训练。可独立重放的薄证据和命令见 `calibration/regularized_bank_20261106/README.md`，完整本机工作包不自动公开。

## 参考曲线主导开发候选

在校准页显式选择“参考曲线主导开发候选（四样品）”可生成 `fixed_h_reference_dominant_transfer_v4`。V4 在 V3 候选上加入三种零原生残差权重的岭回归候选。每个留出折只用其余三个牌号选参。四个保存折均选中零残差，标定拟合仍沿用原样品对应曲线。V4 的留出平均 RMSE 为 0.01385 T，最大绝对 B800 误差 0.01988 T。数据中心可选择 V3 和 V4 下载逐方向对照。

排除牌号预测会重建实际训练子库。材料 metadata 记录版本、实际原生权重和物理 H 轴。原生权重为零时，跨材料曲线由训练参考曲线、材料参数和磁化约束决定。数值来自同四组已有目录参考的回顾性对照。通过历史默认入口打开时仍使用 V2，V4 记录可通过链接或历史列表重开。
