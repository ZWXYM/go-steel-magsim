# 脚本任务历史与重开

从系统首页或“运行MuMax3仿真”进入“脚本执行历史”。新作业在当前工作目录的 `data/script_jobs/` 保存带修订号的状态、创建目录、所属服务实例与请求回执；完整执行日志为 `stdout.log`，原始输出字节为 `stdout.raw`。清理当前服务的已完成卡片保留历史和日志。

新服务可只读查看旧记录，不自动恢复排队、启动或停止原任务，也不因重开服务把“运行中”改称“完成”或“已停止”。历史页显示保存状态、所属实例和保存时间，当前进程状态另标为未核对。需要新计算时从原平台显式新建执行；相同请求ID仍返回原作业，不会因重开或清理卡片重复下发。

初始历史记录不可写或修订冲突时不启动脚本。执行中日志写入异常会显示提示，读取线程会继续排空输出并等待原进程退出，原仿真文件不变。元数据原子替换，低修订号不能覆盖较新状态；坏记录独立显示。历史下载绑定当时的工作目录，换目录后需刷新。

实时控制台同时支持后端逐行 `line` 与兼容批量 `lines`，旧面板与迟到回调隔离保持。测试使用临时目录、模拟进程及独立Python解释器，未为本功能重算MuMax或电机。

“系统状态与问题报告”也会列出当前主平台目录的脚本历史摘要，包括原执行目录、实例、保存状态和单项读取错误。下载保存页面已显示的同一份快照；工作目录在开始读取时固定，读取过程中切换目录不会把两份历史混入报告。摘要不读取完整日志，不包含标准输出、环境变量或其他未列明字段；完整日志仍从脚本历史页下载。
