# 校准材料的转矩分析执行

本轮把已保存的 B-H 分析计划接到独立执行记录和专用 worker。流程为“实际材料导入 → 分析工程复制 → 准备执行 → 手动开始 → 官方转矩 CSV → 汇总下载”。复用作者扫描程序的官方报表导出；原牌号扫描和优化入口保持可用。

## 页面与操作

从材料库打开已有校准电机记录，再进入分析计划。实际原生导入成功并完成工程复制后，页面才允许“准备执行任务”。准备只冻结输入，不启动 AEDT。每个执行记录由用户手动开始一次，页面可重开、刷新状态和下载结果。

执行任务保留材料 AMAT、metadata、实际工程、来源包及程序哈希。材料级排除、父库与有效库、物理 H 轴贯穿计划、任务与结果。派发前重新核对来源和实际保存工程；已有执行痕迹不能重复下发。任务与既有扫描、材料导入共用执行锁，活动任务或身份不明的会话会阻止另一个原生任务下发。

## 执行与整理

每个新任务固定最多一个专用 AEDT 会话、一次电机分析、2 核、0 GPU、1200 秒。支持 1 周期 31 点或 3 周期 91 点协议；worker 先实际应用周期、时间步和停止时间，保存核对 48 插片材料/坐标系、运行点及原损耗对象，原生预检通过后才调用分析。

完成后只收集官方 `-Moving1.Torque` CSV，计算平均/最大/最小转矩和转矩脉动，三周期协议另保留周期间转矩差。页面把新材料结果与既有参考分别显示，可下载原 CSV、JSON、汇总 CSV 和冻结包。参考曲线不会作为本次校准材料的求解结果。

预算超时写入独立 attention 标记，保留现场，不自动杀进程或重试。worker 在后续步骤前检查预算；已开始的原生调用若延迟完成，明确记录超预算完成。仅通过进程身份核对释放本任务新建的专用会话；已有或归属不明的会话不关闭。失败、未完成和清理未确认状态可以重开查看。

B-H 材料没有独立标定损耗系数，本入口只提供转矩分析，效率及最终优化排名禁用。转矩周期差不能代替含损耗的完整稳态验收。
