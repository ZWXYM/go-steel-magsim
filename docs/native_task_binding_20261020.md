# 原生仿真任务的页面绑定

原页面从已准备任务A切换到B、B读取尚未结束时，A的开始按钮仍可点击；先前轮询返回也可能重新选回A。使用原脚本和模拟网络复现：错误目标/start请求1次，旧轮询重新选回A。实际没有下发仿真。

现在切换立即解除旧任务的操作与下载绑定。读取完成、返回身份与所选任务一致后，才按该任务的状态、生产器版本和原预算启用操作。清空选择会清除旧任务及run网址参数。较早的读取、轮询和操作响应不能覆盖新选择，也不能将刚开始的任务倒退显示为旧ready状态。

开始、暂停和现场检查都使用固定任务ID，等待返回期间保持单次请求。操作响应身份不符或网络结果不明确时，提示检查原任务，不自动重试。CPU实例、预算耗尽、旧生产器、失败和已完成任务继续禁止开始；已兼容且有剩余预算的任务仍可显式开始或接续，GPU授权不变。准备新任务同时校对保存参数与请求参数，失败不会重新激活先前任务。

原MuMax生产器、worker、取向采样、原生对导出、队列及120秒累计预算均未改变。测试覆盖模拟切换、重复操作、轮询交错、准备参数不符和资源读失败；错误目标请求由1降为0，正确任务仍可手动请求1次。真实网页只重开已完成DEMO任务、清空并再次重开，保持2/2与21.406秒；没有新准备、GPU或电机求解。4983个旧存储文件集合及SHA不变。
