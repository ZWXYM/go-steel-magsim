# 空气界面方向对照：只完成 CPU 准备（2026-10-07）

`calibration/diagnostics/air_interface_20261007/planned_v1` 冻结三个后续小模型假设；本检查点没有新增原生求解，累计 Maxwell 34、MuMax3 680 保持。执行入口尚未实现，不得把协议中的计划次数或解析场当作完成结果。

当前同质 coupon 的四边固定向量势会直接固定均匀 B，方向变化容易只在总能量中显现，而 H 字段又与原生总能量矛盾。新假设将 20×20 mm 区域分为各向异性材料和空气两个相邻半区，界面 x=0；两个简单线性控制仍使用 μr=(1000,100,1000)，这些是解析对照常数，不是新样品实测参数。

取 Bx 连续、Hy=0。给定目标框架的磁阻率张量 ν，材料中 By=−νyx/νyy×Bx，Hx 由 νB 得到；空气中 By=0、H= B/μ0。法向 B 与切向 H 在无表面电流界面连续。制造解的外边界向量势为 Az=Bx·Y−By材料·min(X,0)，只施加在六条外边，内部界面不能施加固定向量势。

三项计划分别是显式 object-CS 轴向量、相同 relative-CS、忽略方向的全局张量负对照。前两项应该匹配同一个 B/能量制造解；第三项在这个目标 B 下产生非零界面 Hy，故不能是同一个均匀物理解。通过材料/空气两侧的 B、均匀性、官方总能量和 adaptive 记录核对方向，解析 H 只供边界连续性推导，不能替换原生 H。

数学构造、各向同性轴退化、计划与执行的状态分离、非法输入拒绝共四项测试通过。预算只准备：最多三项、2 CPU 核、0 GPU、每项 120 秒、6 pass、0.1% adaptive 门限；没有自动提交，也没有调用 AEDT。
