# 高磁导率线性基线与源曲线段审计（2026-10-07）

`high_mu_linear_v7` 的两个常磁导率对照均通过原 B/H、自适应收敛及追加原生总能量门限。累计 Maxwell 完成 36 项（4 电机、32 磁静态），MuMax 保持 680。没有新电机求解或训练。

第一个对照使用冻结 B23R075 在物理 H=20 A/m 处的 RD/TD 割线磁导率，RD μr 约 60298.88。第二个使用前一节点区间的差分斜率，并由该常磁导率独立计算期望 H。两者没有把失败非线性结果重新标注为 H=20。线性对照可解说明本预算下的高磁导率本身不足以解释既有非线性失败；不能据此认证真实曲线。

`high_mu_linear_v6` 在求解前因浮点数严格相等检查拦截，实际求解为 0。AEDT 保存十进制参数导致约 4.8×10⁻¹⁶ 的相对末位差；v7 仅将标量传输核验改为 10⁻¹² 相对容差，B/H、能量与自适应物理门限保持。失败目录和原 producer 保留。

四样品共 8 条冻结 RD/TD 曲线的逐段 CPU 审计保留每条原有 26 点。各段斜率为正；物理 H=20 节点的分段反插值均为 20 A/m。RD 峰值差分 μr 约 69518–79584，TD 约 6321–7113。这是源段计算，不能代表 Maxwell 内部插值、测量证实或已识别的失败原因。

薄证据位于 `calibration/linear_and_air_20261007`，包含冻结 producer、线性 B/H 与官方逐 pass 收敛、原生定义摘录、源段审计和空气界面 CPU 计划。完整 AEDT 工程、缓存、profile 和日志仅保存在私有工作区。空气计划的原生表达式与边界拓扑尚未执行核验，详见 [空气界面准备](air_interface_preparation_20261007.md)。

主工作区本地检查点全套 181 项测试通过。校准 bank、材料留出误差、原有五扫描状态均保持；真实非线性材料、完整方向接口、独立损耗、稳态电机及最终排名仍未通过。
