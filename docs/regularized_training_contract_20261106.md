# V3标签与现有训练数据约定

可选校准V3纳入已有数据版本检查。此前仅列举V1/V2，新版本标签会进入通用历史数据分支；现已补齐，沿用原有物理版本、物理H轴、校准摘要及原生质量字段要求。未新增门限，也不修改任何保存模型或数据。

新增反例证明修复前V3缺少质量合同未被拒绝；修复后与V2接受、拒绝范围一致。两个既有训练入口均在训练开始前拒绝H轴、物理版本或校准摘要不符的V3数据。标定拟合诊断、预测诊断及原生质量未满足的记录不会自动升级为正式训练标签；新候选可用于B-H校准和出口，并不因此宣称已经完成代理重训。

此更改未进行训练、MuMax或Maxwell求解，不修改V3 bank/协议/曲线，也不涉及GPU授权状态。
