# 电机结果浏览与系统加载流程

本次集中改善已有系统的使用流程，复用保存的校准和电机结果，未增加 MuMax3、Maxwell 或训练任务。

## 新增功能

- 旧 V8_2 final 结果独立展示六案指标，区分同版本 CSV 复核与原保存摘要。缺少 final CSV 时仍显示作者保存的摘要，不替换成其他版本数据。异常案保持可见。
- 每案提供原摘要与该 final 目录内 CSV 的下载；不开放原生项目、缓存或其他结果版本。
- 一键生成新的历史汇总包，包含 CSV/JSON 指标、整理说明、逐案原文件和 SHA256 来源记录。原目录和原文件不改写；导出过程中若来源改变则停止并保留新导出现场。
- 校准、样品、电机目录、历史结果和扫描队列独立加载。单一模块不可访问时其余功能仍可使用。打开页面自动加载最新保存校准，避免重复拟合。
- 队列轮询等待上次读取结束后再安排下一次，避免读取堆叠。

## 操作

启动现有工作台，进入“电机牌号扫描”，下方“已有 V8_2 结果与下载”可查看历史结果。点击“下载旧结果汇总与证据包”，再下载完整包或单独指标 CSV。新牌号扫描仍通过选择牌号、生成独立任务、提交串行队列进行。

本机需要配置 `GO_STEEL_THESIS_ROOT` 指向完整资源工作区；公开仓库没有完整私有电机模型。CPU 模式允许校准、预测、准备和汇总，原生提交仍由该窗口的资源策略控制。CPU 窗口不改变其他窗口的 GPU 授权。

## 验证

新增七项后端回归覆盖摘要保留、同版本 CSV 核对、单案损坏隔离、来源哈希绑定、原始文件不变、下载范围与 CPU 路由。`tests/test_workbench_ui.js` 直接执行页面启动脚本，模拟电机目录不可访问并恢复，验证其他模块不会被连带阻断。可分别执行：

```powershell
python -m unittest discover -s tests -p test_motor_archive.py -v
node tests/test_workbench_ui.js
```

这些是系统功能检查，不新增材料精度或物理认证。源指标口径、历史异常与零损耗材料效率限制保持。
