# 实测回线损耗核算

从系统首页或厂家损耗参考打开“实测回线损耗核算”。上传一条完整周期的 UTF-8 CSV，保留原始采样顺序。使用 `H_A_per_m` 或 `H_kA_per_m` 配一列 `B_T`、`J_T`、`B_mT` 或 `J_mT`。填原测量频率和来源。需要比损耗时填写有来源的试样密度。对于来源已明确第一列 H 为 A/m、第二列 B 为 T 的无表头文件，可以选择“分号分列，小数逗号”。系统按所选单位解析，不自动猜测列或单位，下载仍保留上传原字节和原始行号。

按顺序使用闭合梯形积分，原表是 B 时计算 ∮H dB，原表是 J 时计算 ∮H dJ。两种积分在闭合周期上等价，程序同时记录两者和差值。尾点到首点补一条线段，页面显示首尾差及该段的积分贡献，便于回查周期截取。每周期体积损失乘频率得 W/m³；已知密度时再除以密度得 W/kg。

结果页和数据中心可重开。ZIP 保留原文件字节、物理 H/B/J 和每段积分、频率与密度来源。周期与测量条件以输入记录为准。不同频率、方向和试样应分别保存和核对。已有目录损耗系数与材料库不随核算更新。

同试样有三档或以上频率时，可从结果页进入“合并同试样多频回线”。各档用相同的来源、试样、方向、方法与共同条件，单独填写频率；整理时按原 B/J 峰值范围筛选。见[多频留出复核](frequency_loss_validation.md)。

用 Massimo Pasquale 发布的 HEFMAG 样例核验了两试样六条 50 Hz 回线，共 24,000 点。GO 示例的三个名义峰值 J 1.5、1.7、1.8 T 分别得到体积功率损耗 5727.790、7604.994、9422.261 W/m³。示例的试样牌号、方向和密度待核，完整核算指标见 `calibration/measured_loop_workbench_20261111/benchmark.json`。[HEFMAG 样例原数据](https://doi.org/10.5281/zenodo.5910893)

补充实测回放：[Silva 等发布的无取向钢数据](https://doi.org/10.17632/hgzgpcvjxk.1)可直接导入原回线。RD 试样、0 MPa、约 1 T，1/50/100 Hz 三档共 13,000 原点。以 1 和 100 Hz 估计 50 Hz，插值为 1.055291 W/kg，原回线积分为 1.083685 W/kg。该结果核验导入与多频流程，不接入项目四牌号。来源和核对指标见 calibration/nog_rd_multifrequency_replay_20261112/。
