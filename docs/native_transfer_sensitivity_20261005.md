# 原生残差与泛化波动诊断（2026-10-05）

本轮实现 `fixed_h_native_sensitivity_v1`，从现有 64 份原生 table 自动生成逐粒/分支、固定权重对照及晶粒敏感性报告。上一轮四个外层 bank、候选、划分、物理 H、Msat 和误差窗口均未重新选择；没有新增 MuMax/Maxwell 求解。现行 `fixed_h_nested_transfer_v2` 保持试验身份，旧模型和材料不覆盖。

## 固定模型拆分结果

| 同一冻结外层权重，8 个材料方向 | 平均 RMSE / T | 最坏绝对 B800 误差 / T |
|---|---:|---:|
| 现行模型，保留 beta=0.5 原生残差 | 0.04404265 | 0.10615669 |
| 固定相同权重、仅参考插值的诊断对照 | 0.02015557 | 0.06516457 |
| 固定权重和 beta，使用晶粒约束前中点的诊断对照 | 0.04404240 | 0.10615669 |

加入原生项使整曲线 RMSE 在全部 8 个方向上增大；B800 绝对误差只有 1/8 方向改善。本次 beta=0 对照使用各外层 bank 的同一组权重，区别于上一轮 IDW 的“仅参考对照”。对照不是部署模型，也没有依据成绩重新选参，其最坏 B800 仍超过 0.05 T。不能将该回顾性拆分称为新的独立达标算法。

在 H800，全部 8 组原生均值的逐粒 guard 改动为零；去掉该阶段 guard 的对照几乎不改变整曲线误差。因此，现有 n8 留出表现不能归因于 H800 的逐粒约束。之前 Haar/N128 的大幅 guard 属于另一采样协议，不能合并判断。

现有 n8 在 H800 的原生均值约 0.00169–0.12764 T，两分支逐粒绝对分离的均值约 3.518–3.904 T。程序使用的是大回线两分支中点代理，参考是已处理的第一象限曲线。分支和少量晶粒响应的变化需要继续检查；不能通过换分支、挑晶粒或解释为真实材料 Hc/Br 直接修复误差。

## 配对重采样与约束影响

预先固定 512 次、PCG64 seed=20261005。每个材料从其 8 个已观测晶粒有放回抽取 8 个；RD/TD 共享晶粒编号和 Euler 来源，不同材料独立抽取。预测使用原权重和 beta，参考不抽样，候选不重选。分别扰动目标、训练和两者；所有模式复用同一批索引。

| 外层材料 | 方向 | 原生项 B800 贡献 / T | 两者扰动后 B800 的 2.5%–97.5% 跨度 / T | 最终 guard 前跨度 / T |
|---|---|---:|---:|---:|
| B23R075 | RD | +0.08851 | 0.00079 | 0.23798 |
| B23R075 | TD | −0.03257 | 0.23600 | 0.23600 |
| B27R090 | RD | −0.04195 | 0.11521 | 0.11521 |
| B27R090 | TD | +0.04987 | 0.20421 | 0.20421 |
| B27R095 | RD | −0.04293 | 0.11227 | 0.11227 |
| B27R095 | TD | −0.04843 | 0.12499 | 0.12499 |
| B30P105 | RD | +0.05663 | 0.03470 | 0.19158 |
| B30P105 | TD | +0.04099 | 0.22541 | 0.22541 |

这是**现有晶粒和固定模型条件下的经验敏感性范围**，不是真实材料置信区间，不包括参考、参数、选参或新 seed 不确定性，也不证明覆盖率。512 次计算不能计为新增材料实验。legacy n8 的 ODF 随 seed 变化，不能从本重采样推断固定 ODF 多 seed 收敛。

最终 guard 对两个 RD 外层隐藏了一部分波动；程序同时保存约束前/后各 H 范围及最大约束改动，不能凭窄范围认定收敛。单独目标/训练扰动见 `sensitivity.csv`：B23R075 TD 主要敏感于训练晶粒，B27R090 TD 和 B30P105 TD 的目标晶粒也明显敏感。这是条件诊断，不能作因果方差归因。

## 程序与复现

公开证据：`calibration/native_transfer_sensitivity_20261005`；主工作区：`calibration/diagnostics/native_transfer_sensitivity_20261005/final`。主目录初版保留，最终记录增加约束前敏感性和完整 producer 绑定，两版评分/权重/模型完全一致，没有据结果调整候选。

公开工程根目录执行：

```powershell
python tools/audit_calibration_native_sensitivity.py --root . --artifact calibration/generalization_20261005/cal_65e506f6e207 --output-dir calibration/new_native_sensitivity
```

主工作区根目录执行：

```powershell
.runtime/magsim/Scripts/python.exe -X utf8 magsim/tools/audit_calibration_native_sensitivity.py --root . --artifact calibration/generalization_20261005/final/cal_65e506f6e207 --output-dir calibration/diagnostics/new_native_sensitivity
```

输出必须是新目录且不得位于原生/冻结模型目录内部。程序先冻结协议及 producer，再核对晶粒任务、script/table/Euler 哈希、物理 H、均值、bank 训练来源及旧预测，输出：

- `report.json`：固定模型拆分、三种条件扰动、分支及 guard。
- `scores.csv`、`sensitivity.csv`：逐项误差、24 个方向/扰动组合的范围。
- `grain_curves.csv`：64 晶粒 × 26 H 点，两支/中点/约束值，无删粒。
- `paired_grain_draws.json`：配对索引，各外层折共享同一批抽取。
- `source_integrity.json`：525 个 pilot 和 26 个冻结校准文件前后 SHA 一致。
- `study_protocol.json`、`frozen_producers/`：版本及实际生产代码。

七项新增合同检查覆盖配对/确定性、外层参考只改评分、禁止重选、零 beta 极限、解析敏感性、guard 遮蔽波动、来源/H/索引边界和真实冻结结果复现。
