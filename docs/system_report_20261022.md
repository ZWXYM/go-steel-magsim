# 系统状态与问题报告

从首页“系统状态与问题报告”读取当前Web地址、程序/资源/存储/主平台目录、Python路径、启动与磁盘源码版本、许可TCP状态及八类已保存任务记录。普通模式与单个Web的CPU预览分别显示，TCP连通仅表示已有许可服务可连接。

报告只读取白名单目录中的小型state/report JSON，不刷新或恢复任务，不启动求解、训练、GPU探测或许可会话。每份状态文件保留SHA与原状态，失败任务和文件读取失败分开表达；坏文件、缺失目录或一个检查项失败不阻断其他内容。单文件最多2MiB、每类最多1000条，超限明确标记，原记录不修改。

“下载当前JSON报告”保存页面当前显示的快照，包含生成时间与完整报告摘要；下载不重新请求或悄悄更新状态。刷新失败保留上次报告及其时间，迟到响应不覆盖最新报告。文件仅下载到本机，没有自动上传。
