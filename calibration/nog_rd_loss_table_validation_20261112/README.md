# 多峰值实测损耗表：1/100 Hz 留出 50 Hz

来源为 [Silva 等，Mendeley Data V1](https://doi.org/10.17632/hgzgpcvjxk.1)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。作者给出无取向电工钢 RD_Sample、0 MPa、正弦 B 的每周期损耗 J/kg。三档表合计 80 点。按发布测量协议的 0.05 T 网格分组，各频率实测峰值相对组值最多偏差 0.002033 T，使用 0.005 T 门限。72 原点组成 24 个共三频的组（0.05–1.20 T）；其余 8 点缺少 100 Hz 档，保留但不填补。只按每行频率把原 J/kg 转为 W/kg，不对 B 插值。

1/100 Hz 训练，留出 50 Hz：双侧每周期插值的平均绝对相对误差为 2.987%，最大 7.881%，24 组均优于最低频按频率正比换算（平均绝对误差 31.496%）。按更严的 0.002 T 门限另算 23 组，插值平均绝对误差 2.934%。实际原表与各组指标同时保留在工作台复算包中；公开目录只含来源哈希、匹配和结果摘要。网页对 48 项估计逐项与独立十进制复算一致。三项拟合不启用。

这是同一发布试样的内部留出，不绑定本项目四个取向钢牌号，不更新材料库或电机参数。
