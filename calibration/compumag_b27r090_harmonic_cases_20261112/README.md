# B27R090 无直流偏置的两组谐波实测

来源为 [ICS TEAM Problem 21e 输入资料](https://www.compumag.org/wp/wp-content/uploads/2021/04/problem21_inputdata_P21e.pdf)第 8–11 页（Fig. A2.5–12）。Case II 为基波加三次谐波，Case III 加三、五次谐波。两种 PDF 提取器核对 560 个单元格，共 140 个 B–H 点和 140 个损耗点。磁场 H 是 B 达峰时的值；未将激励装置参数代填为材料 SST 的频率或谐波幅值。

只以初始表选点的 26 节点候选，在两种谐波实测横向共同低场的 H 计权 RMSE 为 0.02512、0.03250 T，冻结 V4 留出为 0.72039、0.73314 T。两工况未参与选点；同一出版来源没有独立卷号，不当作跨批验证。

在共同磁密内线性插值。1.5 T 下 Case I、II、III 的 TD/RD 比损耗约为 6.01、6.19、6.21。三工况不是三个测量频率，未向电机 100 Hz 换算。公开目录保留来源哈希和派生比较，原表仍在发布方，默认模型和已有电机保持。
