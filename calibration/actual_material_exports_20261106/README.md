# 实际材料与单数据集出口的薄证据

包含四个RD标量方向等效算例的实际材料、104个B-H节点、124个官方转矩点和来源，另有原库五数据集的读取/打包检查摘要。完整原生工程、缓存、profile、日志与私有数据包不公开。

四个同协议结果中仅B27R095通过原转矩判据，其余3项异常。工程比较因此没有另一个合格材料可与基准比较；诊断原值完整保留，不能把异常大值说成性能提升。协议中的stable表示平滑/迭代设置，未证明对四材料普遍稳定。零损耗校准材料不输出效率，单方向等效曲线不认证局部RD/TD。

原作者材料库/优化程序继续沿用；五数据集26行中21行通过各自原判据，包含重复材料和工况，不是26个独立样品。完整私有工作区的原数据包可通过优化页下载；本公开树只保留上述检查摘要。

参见docs/actual_motor_material_exports_20261106.md和docs/motor_dataset_export_20261106.md。CPU解析器、HTTP和真实内置浏览器下载检查分别记录；没有为导出功能新增物理求解。
