# B30P105 50 Hz 实测与厂家损耗对照

将 Li 与 Luo 补充工作簿的每个 H/B 点按 J=B−μ₀H 换算，再以各周期的最大 |J| 连接发布的质量比损耗。将两档宝钢典型 J 值代入表内插值，1.5 T 对应 0.88404 与 0.74 W/kg，1.7 T 对应 1.25673 与 0.99 W/kg。工作簿相对厂典型值高约 19.5% 与 26.9%。工作簿的切割方向和卷号未记录。 [实测来源](https://doi.org/10.1038/s41598-024-55155-w) · [宝钢标准附录 D.1](https://ecommerce.ibaosteel.com/baosteel/manufacturerStandard/pdf2023/BQB%20485-2023.pdf)

按同牌号已保存电机材料系数，在该实测 50 Hz 的实际 B 峰值复算旧损耗模型。名义 1.5、1.7 T 两档低约 12.2% 和 20.6%。电机的保存结果对应 100 Hz 首周期，该对照用于限定材料估计的适用范围。
