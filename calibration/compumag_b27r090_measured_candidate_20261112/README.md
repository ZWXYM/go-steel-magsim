# B27R090 实测区间候选与网格核对

来源为 [ICS TEAM Problem 21e 输入资料](https://www.compumag.org/wp/wp-content/uploads/2021/04/problem21_inputdata_P21e.pdf)第 12 页 Fig. A2.13–14。工作台从确认牌号和方向的实测初始表生成两个实测范围候选，不补零、不外推、不生成 AEDT 材料。保持原资料，单调化只调整两个 RD 原点，最大 0.008435 T；TD 无单调化调整。各 26 节点，对输入原表全区段的 H 计权重建 RMSE 为 RD 0.000543 T、TD 0.001309 T。

把冻结 V4 的 H 网格裁至实测范围并加上两端，TD 只剩 12 节点。即使用实测值直接填这些节点，实测重叠低场的重建 RMSE 仍为 0.2945 T。相同 12 节点按曲线形状分配时为 0.00667 T；26 节点为 0.000403 T。该网格对照衡量可表达的形状，不当成预测误差；RD 采用相同 10 节点时，固定网格的全段 RMSE 反而较低，结论不推广为所有方向都适合相同策略。

仅以初始表选节点；同报告直流/正弦峰值的 TD 低场按各共同 H 范围复核，26 节点候选的 RMSE 为 0.00910/0.02395 T，冻结 V4 留出为 0.72396/0.71941 T。独立计算确认。它们来自同一公开报告，未确认是独立批次；不表示对其他牌号已校正。冻结库、预测、现有电机和软件默认保持。原资料在发布方，公开仓库仅含方法与派生数字。
