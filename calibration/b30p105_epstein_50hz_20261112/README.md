# B30P105 Epstein 50 Hz 实测回线复算

Li 与 Luo（2024）补充工作簿提供 20 个正弦周期，各 1000 个原序 H/B 点，以及 20 个配套的原比损耗值。标注的测试系统是 Epstein 700。切割方向、卷号与试样密度缺失。归档原表的 MD5 与 PMC 元数据一致，两个读取方式核对 80193 个有效单元格。 [实验论文](https://doi.org/10.1038/s41598-024-55155-w) · [原工作簿](https://pmc-oa-opendata.s3.amazonaws.com/PMC11043459.1/41598_2024_55155_MOESM1_ESM.xlsx) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

20 条回线的网页核算与独立闭合面积复算一致。在名义 1.5 T，原比损耗 0.883887 W/kg，积分体积损耗 6823.679 W/m³。H 在 B 峰值的同一采样行读取为 50.667 A/m，原 Results Hmax 为 53.519 A/m。名义 2 T 的实测峰值为 1.976960 T。`benchmark.json` 保存校验值与派生汇总。本复算适用于该发布来源的 50 Hz 多幅值回线。
