# 无取向电工钢原回线的多频核对

数据来自 [Silva 等，Mendeley Data V1](https://doi.org/10.17632/hgzgpcvjxk.1)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。保留作者发布的 RD_Sample、0 MPa、约 1 T 的 1/50/100 Hz 原回线身份与 SHA-256。手册 §2.1 表 1 给出 RD 试样密度 7,845 kg/m³；§3.1–3.2 及作者示例脚本确认表面 H（A/m）和 B（T）两列。程序未运行作者脚本。

工作台直接读取无表头、分号分列、小数逗号的源表，保留 10,000、2,000、1,000 个采样点及最后闭合段。原回线积分与独立多边形面积复算一致。以同频、同工况最近的原损耗表磁密点对照，三档比能量差 -0.600%、-0.346%、+0.287%；最近点磁密与回线实际峰值的差和行号见 benchmark.json。这是同一发布数据集内的交叉核算。

以 1 和 100 Hz 的每周期比能量线性插值，留出 50 Hz：回线积分 1.083685 W/kg，插值 1.055291 W/kg（-2.620%），仅用最低频按频率成比例为 0.660960 W/kg（-39.008%）。实际最大 |B| 与 1 T 偏差小于 0.2 mT；两档训练频率不足以拟合三项系数。原文件及作者脚本可从数据发布者取得，本目录只记录数据来源、校验值和派生核对结果。

材料是无取向电工钢；核对支持测量导入与多频复算，不用于四个取向牌号的校准、外推或电机参数。
