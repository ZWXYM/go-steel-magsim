# B27R095 单片试样直流偏磁实验

赵小军等用 Brockhaus 单片测试仪测量 100×500 mm B27R095。准静态测试为 4 Hz，表 2、3 各列 5 个带偏磁的饱和段测量值及论文模型值，表 4 列 5 个实测比损耗值。45 个表格数值逐项核对期刊表图和 HTML 文本。方向与卷号未记录。 [期刊原文](https://dgjsxb.ces-transaction.com/fileup/HTML/2020-9-1849.htm) · [DOI](https://doi.org/10.19595/j.cnki.1000-6753.tces.190603)

表 4 的 0.8 T 行保留原文 43.48 个百分点，由同一行三个损耗值复算为 46.09 个百分点。图 4 的 50 Hz 损耗另作图读，取图轴 1.0 T 时，0、25、50 A/m 偏磁约为 0.28、0.38、0.45 W/kg。图读分辨率约 0.01 W/kg，横轴沿用原图 B/T 标记。数字表与图读的频率和来源分别记录。
